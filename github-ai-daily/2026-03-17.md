## 1. 核心仓库更新细项

### anthropics/claude-code · v2.1.77
- 发布时间：2026-03-17 08:28（北京时间）
- 链接：https://github.com/anthropics/claude-code/releases/tag/v2.1.77

#### 这次具体更新了什么
1. 把 Claude Opus 4.6 的默认最大输出 token 提高到 64k，上限提高到 128k。
2. 新增 `allowRead` 沙箱文件系统设置，允许在 `denyRead` 区域里重新放开部分读取权限。
3. `/copy` 支持可选索引，`/copy N` 可复制倒数第 N 条 assistant 回复。
4. 修复复合 bash 命令（如 `cd src && npm test`）的 “Always Allow” 规则保存错误，减少重复权限弹窗。
5. 修复 auto-updater 在界面重复开关时重叠下载二进制、吃掉大量内存的问题。
6. 修复 `--resume` 因 memory-extraction 与主 transcript 竞争而截断最近对话历史的问题。
7. 修复 PreToolUse hooks 返回 `allow` 时绕过 `deny` 权限规则的问题，包括企业托管设置。
8. 修复 Write 工具覆盖 CRLF 文件时悄悄改行尾的问题。
9. 修复长会话里 progress message 在 compaction 后残留，导致内存持续增长。
10. 修复 API fallback 到非流式模式时，cost 和 token usage 不被统计的问题。
11. 修复 tmux 里的背景色、剪贴板复制、iTerm2 选中文本崩溃、IDE integration 自动连接等一批终端/IDE 兼容问题。
12. 修复 stale-worktree cleanup 竞态，避免刚恢复的 agent worktree 被误删。
13. `SendMessage` 现在会自动恢复已停止的 agent；`Agent` 工具不再接受 `resume` 参数。
14. `/fork` 重命名为 `/branch`（`/fork` 仍保留兼容别名）。

#### 我会怎么理解
这版不是“新能力大爆发”，而是典型的“真实使用补丁包”：长会话、权限、tmux、IDE、worktree、resume、统计、插件校验都在补。说明 Claude Code 已经进入重度用户打磨阶段。

### openclaw/openclaw · v2026.3.13-1
- 发布时间：2026-03-15 02:04（北京时间）
- 链接：https://github.com/openclaw/openclaw/releases/tag/v2026.3.13-1
- 说明：这是恢复型 release；npm 版本仍是 `2026.3.13`，`-1` 只用于 Git tag / GitHub Release。

#### 这次具体更新了什么（核心挑选）
1. 修复 compaction：改为使用完整会话 token 数做压缩后的 sanity check。
2. 修复 Telegram：把 thread media transport policy 接进 SSRF 防护链路。
3. 修复 session reset 后 `lastAccountId` / `lastThreadId` 丢失的问题。
4. 更新测试里的默认模型到 `openai-codex/gpt-5.4`。
5. 修复 agents replay 时重复注入 memory file、thinking blocks 重放等问题。
6. 增加 Docker `OPENCLAW_TZ` 时区支持。
7. 修复 browser batch dispatch、session lifecycle、existing-session driver validation 等 browser 链路问题。
8. 修复 Feishu：保留非 ASCII 文件名、增加 event 级去重，避免重复回复。
9. 修复 cron：防止 isolated cron 嵌套 lane deadlock。
10. 修复 gateway：限制未应答 client requests，改进 degraded reachability 判定。
11. 修复 macOS：避免 PortGuard 杀掉 Docker Desktop；gateway prompter 尊重 exec approvals 设置。
12. 修复 UI：聊天历史 reload storm、可读性、context notice icon、scroll pill、shared auth 等大量细节。
13. 修复 Signal groups schema、web fetch firecrawl config、config schema 缺失字段等配置问题。
14. 增加 Slack interactive replies；iOS onboarding pager；Android chat settings UI redesign。
15. 修复 cross-agent subagent spawn 的 workspace 解析问题。
16. 修复 Feishu、Telegram、Discord、browser、gateway、Docker build context 等多处安全/稳定性问题。

#### 我会怎么理解
这版虽然名义上是恢复 release，但实际是“系统修补大包”。OpenClaw 真正值得跟的地方，不只是 agent 能力，而是这些分布在 gateway / browser / cron / session / UI / channel / security 的基础修补。
