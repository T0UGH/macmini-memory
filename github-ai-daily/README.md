# GitHub AI Daily

Daily GitHub open-source intelligence reports.

## Defaults
- Timezone: Asia/Shanghai
- Delivery time: 08:30 daily
- Surface delivery: Feishu summary only
- Archive: full markdown in this directory
- Focus: all AI OSS, with emphasis on agent/coding, MCP/Claude ecosystem, skills/workflows, and spec/protocol projects
- Method: watchlist repos + new repo discovery
- Git policy: auto commit + push

## Coverage priorities
- Track a core watchlist of 20-30 repos
- Discover promising new repos
- Highlight releases, high-signal issues/PRs, roadmap changes, star acceleration, and adoption signals
- Include a dedicated section for Skills / Workflow changes
- Include a dedicated section for Spec / Workflow / Protocol changes

## Scoring dimensions
Each item should include:
- Importance
- Technical Depth
- Practical Value
- Relevance to user
- Programmer Survival Index

## Author + link rules
- Full markdown items should include repo owner/name and direct GitHub links.
- Feishu summary should stay concise and include the GitHub report link at the end for full reading.
