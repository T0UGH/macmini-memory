# Claude Code Changelog - 2026-03-09 检查

## v2.1.71（2026-03-07 发布）

### 新功能

- **`/loop` 命令**：支持定时循环执行 prompt 或 slash 命令（如 `/loop 5m check the deploy`）
- **Cron 调度工具**：会话内可设置定时任务
- **Voice 按键可自定义**：`voice:pushToTalk` 可在 `keybindings.json` 中绑定为 `meta+k` 等组合键
- **Bash 自动允许列表扩展**：新增 `fmt`、`comm`、`cmp`、`numfmt`、`expr`、`test`、`printf`、`getconf`、`seq`、`tsort`、`pr`

### Bug 修复

- 修复长时间会话中 stdin 冻结（按键无响应但进程仍存活）
- 修复系统唤醒后 CoreAudio 初始化导致的 5-8 秒启动卡顿（Voice 模式用户）
- 修复多个 claude.ai 代理连接器同时刷新 OAuth token 导致启动 UI 冻结
- 修复 `/fork` 分叉对话共享同一 plan 文件导致互相覆盖
- 修复 Read 工具在图片处理失败时将超大图片放入上下文
- 修复 heredoc commit message 中复合 bash 命令的误报权限提示
- 修复多实例运行时插件安装丢失
- 修复 claude.ai 连接器在 OAuth token 刷新后重连失败
- 修复组织配置连接器的重复启动通知
- 修复后台 Agent 完成时通知缺少输出文件路径
- 修复 Bash 工具非零退出状态时输出重复
- 修复无本地 Chrome 时扩展检测永久显示"未安装"
- 修复 `/plugin marketplace update` 合并冲突
- 修复插件市场 `@ref` 解析问题
- 修复 `/permissions` 中目录末尾斜杠导致的重复条目
- 修复配置 team agents 时 `--print` 无限等待
- 修复每次 `ToolSearch` 调用后显示 "❯ Tool loaded."
- 修复 Windows mingw 路径下不必要的 git 权限提示

### 性能改进

- 延迟加载原生图片处理器到首次使用，加快启动速度
- Bridge 会话在笔记本唤醒后数秒内重连（之前最多 10 分钟）
- 插件卸载改为在 `.claude/settings.local.json` 中禁用，避免影响团队成员
- 插件 MCP Server 去重：跳过与手动配置重复的服务器

### 其他变更

- `/debug` 改为切换式调试日志（不再默认写入）
- 移除未认证组织注册 claude.ai 连接器的启动通知噪音
