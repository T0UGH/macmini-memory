# Claude Code Changelog — 2026-05-02

## v2.1.126 — 2026-05-01

> 上次更新距今日 1 天

### 主要更新

- **模型选择器**：当 `ANTHROPIC_BASE_URL` 指向 Anthropic 兼容网关时，现在会从网关的 `/v1/models` 端点拉取模型列表
- **新增命令**：`claude project purge [path]` — 删除所有 Claude Code 状态（transcripts、tasks、文件历史、配置条目），支持 `--dry-run`、`-y/--yes`、`-i/--interactive`、`--all`
- **权限绕过**：`--dangerously-skip-permissions` 现可绕过 `.claude/`、`.git/`、`.vscode/`、shell 配置文件等受保护路径的写入确认
- **SSH/WCL2 登录**：`claude auth login` 现支持粘贴浏览器回调的 OAuth code，解决 localhost 无法访问场景下的认证问题
- **OpenTelemetry**：`claude_code.skill_activated` 事件新增 `invocation_trigger` 属性（`user-slash` / `claude-proactive` / `nested-skill`）
- **Auto Mode**：权限检查卡顿时 spinner 现在会变成红色
- **Windows 改进**：PowerShell 7 检测增强；PowerShell 工具现作为主要 shell
- **安全修复**：修复 `allowManagedDomainsOnly` / `allowManagedReadPathsOnly` 在某些配置下被忽略的问题
- **其他修复**：图片粘贴大于 2000px 时自动缩放、OAuth 登录超时、流空闲超时、日本/韩国/中文文本在 Windows 上的渲染问题等 30+ 修复
