# Claude Code Changelog — 2026-06-20

## v2.1.183 (2026-06-19)

**发布时间：** 2026-06-19T01:20:50Z

**主要更新：**

- **安全强化（Auto Mode）：** 未主动要求时禁止 `git reset --hard`、`git checkout -- .`、`git clean -fd`、`git stash drop` 等破坏性操作；`git commit --amend` 仅限本会话 Agent 创建的提交；`terraform destroy` / `pulumi destroy` / `cdk destroy` 需要明确要求
- **废弃模型警告：** 请求废弃模型或自动切换模型时新增警告提示（stderr），并扩展支持 agent frontmatter 中的模型设置
- **新增 `attribution.sessionUrl` 配置：** 可在 web/Remote Control 会话中隐藏 commit/PR 中的 claude.ai session 链接
- **交互体验优化：** `/config --help` 新增所有快捷键列表；`/config` 对话框中 Enter 和 Space 均切换选项，Esc 保存并退出
- **UI 修复：** 修复 Windows Terminal 全屏模式 TUI 损坏、vim 模式下终端光标异常、subagent 思考块为空时静默完成等问题
- **其他修复：** WebSearch 子代理空结果修复、tmux teammate 启动卡顿修复、定时任务/webhook 误识别为键盘输入等

**Release：** https://github.com/anthropics/claude-code/releases/tag/v2.1.183

## v2.1.181 (2026-06-17)

**发布时间：** 2026-06-17T22:07:41Z

**主要更新：**

- **新 `/config key=value` 语法：** 可直接在提示符中设置任意配置项（如 `/config thinking=false`），支持交互模式、`-p` 和 Remote Control
- **新增 `sandbox.allowAppleEvents`：** macOS 沙箱命令可选允许发送 Apple Events
- **新增 `CLAUDE_CLIENT_PRESENCE_FILE`：** 指向标记文件可在本地使用时抑制移动端推送通知
- **Bun 运行时升级至 1.4**
- **长段落流式输出优化：** 文本逐行出现，不再等待第一个换行符
- **API 连接稳定性：** thinking 过程中断线自动重试，不再显示 "Connection closed while thinking"
- **Subagent 面板优化：** 空闲 30s 自动隐藏、最多 5 行显示、键盘快捷键显示在底部
- **大量修复：** 包括自定义 `ANTHROPIC_BASE_URL` 下的 prompt caching 读取问题、网络/云同步目录 Write/Edit 截断、macOS auth 流程 -600 错误、启动阻塞回归（~120ms）、`.claude.json` 损坏导致崩溃等

**Release：** https://github.com/anthropics/claude-code/releases/tag/v2.1.181
