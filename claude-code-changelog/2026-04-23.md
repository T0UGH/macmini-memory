# Claude Code Changelog — 2026-04-23

## v2.1.118 (2026-04-23)

**主要更新：**
- 新增 Vim 可视模式（`v` 和 `V`），支持选择、操作符和可视反馈
- 合并 `/cost` 和 `/stats` 为 `/usage`
- 新增自定义主题管理：`/theme` 可创建和切换命名主题
- Hooks 现可直接调用 MCP 工具（`type: "mcp_tool"`）
- 新增 `DISABLE_UPDATES` 环境变量，阻止所有更新路径
- WSL on Windows 现可继承 Windows 端管理的设置

**Bug 修复：**
- 修复 `/mcp` 菜单隐藏 OAuth 操作的问题
- 修复 MCP OAuth 刷新问题及 macOS keychain 竞态条件
- 修复 Linux/Windows 上凭据保存崩溃导致 `~/.claude/.credentials.json` 损坏
- 修复 `/fork` 将完整父对话写入磁盘的问题（现改为写入指针）

---

## v2.1.117 (2026-04-22)

**主要更新：**
- Fork 子代理现可在外部构建中启用（`CLAUDE_CODE_FORK_SUBAGENT=1`）
- 改进 `/model`：选择状态跨重启持久化
- MCP 启动加速：并发连接作为默认行为
- macOS/Linux 原生构建：`Glob` 和 `Grep` 工具替换为内置 `bfs` 和 `ugrep`

**Bug 修复：**
- 修复 Plain-CLI OAuth 会话因 token 过期中断的问题
- 修复 Opus 4.7 会话 `/context` 百分比虚高问题
- 修复 SDK `reload_plugins` 串行重连用户 MCP 服务器的问题
