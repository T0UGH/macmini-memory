# Claude Code Changelog — 2026-04-25

> 来源：[code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)

---

## v2.1.119 — 2026年4月23日

### 主要更新
- **`/config` 设置持久化**：配置现在自动写入 `~/.claude/settings.json`，支持项目/本地/策略层级覆盖
- 新增 `prUrlTemplate` 配置项，自定义 PR badge URL
- 新增 `CLAUDE_CODE_HIDE_CWD` 环境变量，隐藏启动 Logo 中的工作目录
- **`--from-pr` 支持扩展**：新增 GitLab MR、Bitbucket PR 和 GitHub Enterprise URL
- **`--print` 模式优化**：现在正确遵循 agent 的 `tools:` 和 `disallowedTools:` frontmatter
- **Vim 修复**：`Esc` 在 INSERT 模式下不再将队列中的消息拉回输入区
- **OpenTelemetry 增强**：`tool_result` 和 `tool_decision` 事件新增 `tool_use_id` 和 `tool_input_size_bytes`
- 修复 CRLF 内容粘贴时多出空行的问题
- 修复 MCP OAuth 客户端密钥在 token 交换时未发送的问题
- 修复 MCP server `headers` 中 `${ENV_VAR}` 占位符未替换的问题
- **安全**：`blockedMarketplaces` 现在正确强制执行 `hostPattern` 和 `pathPattern`

---

## v2.1.118 — 2026年4月23日

### 主要更新
- **新增 Vim visual mode**（`v`）和 visual-line mode（`V`），支持选择、operator 和视觉反馈
- **`/cost` 和 `/stats` 合并为 `/usage`**（两者保留为快捷方式）
- **自定义主题**：通过 `/theme` 或手动编辑 `~/.claude/themes/` 中的 JSON 文件创建/切换主题
- **Hooks 现在可以直接调用 MCP tools**，通过 `type: "mcp_tool"` 定义
- 新增 `DISABLE_UPDATES` 环境变量，禁用所有更新路径
- 新增 `claude plugin tag` 命令，创建带版本校验的 release git tag
- **Auto mode**：在 `autoMode.allow`、`autoMode.soft_deny` 或 `autoMode.environment` 中包含 `"$defaults"` 可在内置列表基础上追加自定义规则
- 修复 macOS keychain 竞态问题（并发 MCP token 刷新可能覆盖 token）
- 修复 `--login` 在使用 `CLAUDE_CODE_OAUTH_TOKEN` 启动时无效的问题

---

## v2.1.117 — 2026年4月22日

### 主要更新
- **外部构建现在可启用 forked subagents**（通过 `CLAUDE_CODE_FORK_SUBAGENT=1`）
- **`/model` 选择现在跨会话持久化**，即使项目指定了不同模型
- **启动速度提升**：本地和 claude.ai MCP server 连接并发加载
- **`/resume` 大会话显著加速**（40MB+ 会话提升达 67%）
- **原生构建**：macOS/Linux 上 `Glob` 和 `Grep` 工具替换为嵌入式 `bfs` 和 `ugrep`（搜索更快）
- **Pro/Max 订阅者默认 effort 提升**：在 Opus 4.6 和 Sonnet 4.6 上默认 effort 从 `medium` 改为 `high`
- **OpenTelemetry 改进**：`user_prompt` 事件新增 `command_name` 和 `command_source`；新增 effort 属性
- 修复 Opus 4.7 会话 `/context` 百分比虚高的问题（原来是按 200K 上下文而非 1M 计算）
