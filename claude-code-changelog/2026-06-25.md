## v2.1.191 — 2026-06-24

**主要更新：**

- **新功能 `/rewind`**：支持从 `/clear` 之后恢复对话，继续之前的会话
- **沙箱网络权限优化**：在会话内对"允许"的Hosts不再重复提示
- **性能提升**：流式输出时 CPU 使用降低约 37%（文本更新合并至 100ms 周期）
- MCP 服务器能力发现失败时自动重试网络错误
- MCP OAuth 请求失败时重试一次；无头环境跳过浏览器弹窗
- 修复流式响应时滚动位置跳动的问题
- 修复后台 agent 从任务面板终止后状态保持停止
- `/voice` 现展示组织策略限制说明而非通用错误
- `/login` URL 正确处理 Windows Terminal 换行
- Ghostty over ssh/tmux 下 Cmd+click 链接修复
- Hooks 中逗号分隔的匹配器（如 `"Bash,PowerShell"`）正常触发
- `/permissions` 最近拒绝标签页关闭后保持状态
- 欢迎页艺术字适配默认 80×24 macOS Terminal 窗口
- `forceRemoteSettingsRefresh` 支持 MDM/file policy 正确使用 `Cache-Control: no-cache`
- 长会话终端输出缓存内存增长降低
- MCP HTTP 404 错误现在展示 URL 并引用 MCP 配置
- Vim 模式提示历史搜索 (`/`) 增加了如何访问斜杠命令的提示
