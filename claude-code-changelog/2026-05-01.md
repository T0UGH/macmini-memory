# Claude Code Changelog — 2026-05-01

> 近 2 天共发布 4 个版本，重点关注 v2.1.126（今日发布）

---

## v2.1.126 — May 1, 2026（今日发布）

**亮点功能：**
- `/model` 选择器现支持显示来自 `ANTHROPIC_BASE_URL` 指向的兼容网关的模型列表
- 新增 `claude project purge [path]` 命令，可删除项目的所有 Claude Code 状态（转录、任务、文件历史、配置）
- `--dangerously-skip-permissions` 现可绕过对 `.claude/`、`.git/`、`.vscode/`、shell 配置文件等保护路径的写入确认
- `claude auth login` 现支持在 WSL2、SSH、容器环境中粘贴 OAuth 验证码完成登录
- Windows：自动检测 PowerShell 7 并优先作为主 shell
- 图片粘贴超过 2000px 自动缩小，解决粘贴大图导致会话崩溃的问题

**安全修复：**
- 修复 `allowManagedDomainsOnly` / `allowManagedReadPathsOnly` 在某些情况下被忽略的问题
- 修复 Windows 剪贴板写入时内容暴露在进程命令行参数中的问题

**Bug 修复：**
- 修复 Mac 从睡眠唤醒后出现 "Stream idle timeout" 错误
- 修复远程会话在模型长思考期间误报 "Stream idle timeout"
- 修复 Windows 非闪烁模式下日/韩/中文文字渲染乱码
- 修复 `Ctrl+L` 行为（现强制重绘而非清空提示输入）

---

## v2.1.123 — April 29, 2026

**Bug 修复：**
- 修复设置 `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` 时 OAuth 认证失败并陷入 401 重试循环的问题

---

## v2.1.122 — April 28, 2026

**新功能：**
- 新增 `ANTHROPIC_BEDROCK_SERVICE_TIER` 环境变量，支持选择 Bedrock 服务层级（`default`、`flex` 或 `priority`）
- 在 `/resume` 搜索框粘贴 PR URL 即可找到创建该 PR 的会话（支持 GitHub、GitHub Enterprise、GitLab、Bitbucket）
- `/mcp` 现可显示被同名手动服务器隐藏的 claude.ai 连接器

**Bug 修复：**
- 修复 `/branch` 产生的分叉会话报错 "tool_use ids were found without tool_result blocks"
- 修复发送给较新模型的照片被错误缩放到 2576px 而非正确的 2000px 最大值
- 修复图片发送给较新模型时尺寸错误

---

## v2.1.121 — April 28, 2026

**新功能：**
- MCP 服务器配置新增 `alwaysLoad` 选项，设为 `true` 时所有工具跳过工具搜索延迟加载
- 新增 `claude plugin prune` 命令，清理孤立的自安装插件依赖
- `/skills` 新增类型过滤搜索框
- PostToolUse hooks 现可通过 `hookSpecificOutput.updatedToolOutput` 替换工具输出
- MCP 服务器瞬态错误自动重试最多 3 次
- Vertex AI 支持基于 X.509 证书的工作负载身份联合（mTLS ADC）

**Bug 修复：**
- 修复处理大量图片时无内存上限增长（多 GB RSS）
- 修复 `/usage` 在大型转录历史机器上泄漏约 2GB 内存
- 修复 Bash 工具在的工作目录被删除/移动后永久不可用
- 修复非全屏模式下 `Ctrl+L` 导致滚动内容重复
- 修复 `/usage` 在 OAuth token 过期后返回 "rate limited"（现自动刷新）
