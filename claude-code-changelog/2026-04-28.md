# Claude Code Changelog — 2026-04-28

## v2.1.121 (2026-04-28)

**Commit:** `158620419486e3d2d696351d5a71fbd6b8f58653`

### 🔥 重点更新

- **MCP 服务器 `alwaysLoad` 选项**：设为 `true` 时，所有工具跳过 tool-search 延迟，始终可用
- **新增命令 `claude plugin prune`**：清理孤立的自动安装插件依赖
- **全屏滚动优化**：向上滚动后输入不再自动跳回底部；对话框溢出时可滚动
- **内存泄漏修复**：处理大量图片时 RSS 不再无限增长；`/usage` 内存泄漏修复；长时间运行工具内存泄漏修复
- **`/terminal-setup` iTerm2 剪贴板支持**：自动启用 iTerm2 剪贴板访问，使 `/copy` 在 tmux 中也能正常工作
- **MCP 服务器自动重试**：启动时遇到临时错误自动重试最多 3 次

### 新功能

| 功能 | 说明 |
|------|------|
| `/skills` 类型过滤搜索 | 长列表中快速筛选，无需滚动 |

| Claude.ai 连接器去重 | 相同上游 URL 的连接器不再重复 |
