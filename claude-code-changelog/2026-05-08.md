# Claude Code Changelog — 2026-05-08

## v2.1.133 (2026-05-07)

### 新增功能
- 新增 `worktree.baseRef` 设置项（`fresh` | `head`），控制 `--worktree`、`EnterWorktree` 和 agent-isolation worktree 从 `origin/<default>` 还是本地 `HEAD` 创建分支。**注意：**默认的 `fresh` 行为将 EnterWorktree 的基准分支回退到 `origin/<default>`（之前从 2.1.128 起是本地 HEAD）——如需保留未推送的提交，设置 `worktree.baseRef: "head"`
- 新增 `sandbox.bwrapPath` 和 `sandbox.socatPath` 托管设置项（Linux/WSL），支持自定义 bubblewrap 和 socat 二进制文件路径
- 新增 `parentSettingsBehavior` admin 级配置键（`'first-wins' | 'merge'`），允许管理员将 SDK `managedSettings`（parent tier）纳入策略合并
- Hooks 现可通过 `effort.level` JSON 输入字段和 `$CLAUDE_EFFORT` 环境变量获取当前 effort 等级，Bash 工具命令也可读取该变量

### 改进
- 改进了 Focus Mode 行为
- 改善内存使用：释放内存压力下的 warm-spare 后台 workers

### Bug 修复
- 修复并行会话在 refresh-token 竞态导致共享凭据被清除后全部卡死在 401 的问题
- 修复 Edit/Write/Read allow 规则作用域为驱动器根目录（如 `C:\` 或 `/`）时匹配错误、总是不停弹窗的问题
- 修复历史/会话日志文件锁被时钟偏移或慢速磁盘破坏时出现未处理的 `ECOMPROMISED` 异常
- 修复对话压缩过程中按 Esc 出现虚假"Error compacting conversation"通知的问题
- 修复 `HTTP(S)_PROXY` / `NO_PROXY` / mTLS 在完整 MCP OAuth 流程（发现、动态客户端注册、token 交换和刷新）中未被正确尊重的问题
- 修复 Read/Write/Edit 在通过 `--add-dir` / SDK `additionalDirectories` 传入的映射网络驱动器上被拒绝的问题
- 修复从 claude.ai 的 Remote Control stop/interrupt 未完全取消 CLI 会话（与本地 Esc 处理方式不同），导致中断后排队消息无法推进的问题
- 修复 `/effort` 在一个会话中意外改变其他并发会话 effort 等级的问题，以及 IDE effort 变更可能被静默丢弃的相关问题
- 修复子 agent 无法通过 Skill 工具发现项目、用户或插件 skill 的问题
- `claude --help` 现在同时列出 `--remote-control` 和 `--remote-control-session-name-prefix`
- [VSCode] 修复扩展内置 SDK 中硬编码 `createRequire` 构建路径导致在 Windows 上激活失败的问题

## v2.1.132 (2026-05-06)

### 新增功能
- 新增 `CLAUDE_CODE_SESSION_ID` 环境变量，注入到 Bash 工具子进程环境，与 hooks 传递的 `session_id` 一致
- 新增 `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` 环境变量，可退出全屏 alternate-screen 渲染模式，保持会话在终端原生滚动缓冲区中
- 新增"正在粘贴…"（"Pasting…"）底部提示，在从剪贴板读取 Ctrl+V 图片粘贴时显示

### Bug 修复
- 修复外部 SIGINT（如 IDE 停止按钮、`kill -INT`）未执行优雅关闭的问题——现在会恢复终端模式并打印 `--resume` 提示，而非突然退出
- 修复终端在原生构建下关闭或 SSH 断开会话时出现未捕获异常的问题
- 修复 `--resume` 在工具错误截断导致 emoji 被分割时报 `no low surrogate in string` 错误的问题；已预先损坏的会话在加载时会被清理
- 修复 `--permission-mode` 标志在通过 `-p --continue`/`--resume` 恢复 plan-mode 会话时被忽略的问题，以及同一会话内 `ExitPlanMode` 后未重新应用 plan mode 的问题
- 修复笔记本睡眠/唤醒或 Ctrl+Z/`fg` 后全屏模式显示空白屏幕，直到下次按键或流式输出才恢复的问题
- 修复在 indic 连音或 ZWJ emoji 跨行时，光标定位到 grapheme 中间的问题
- 修复包含分解（NFD）重音字符的文本在 vim 操作符下被破坏的问题
- 修复以 `/` 开头的粘贴文本静默吞掉输入或触发未知命令回复的问题
- 修复粘贴时光标落入括号粘贴模式但聚焦事件或鼠标追踪报告交错导致多余转义序列进入提示符的问题
- 修复在 Cursor 和 VS Code 1.92–1.104 中鼠标滚轮滚动过快的问题（上游 xterm.js bug）
- 修复 JetBrains IDE 2025.2 终端中滚轮处理错误（虚假方向键、错误方向事件、失控加速）的问题
- 修复 `/usage` Ctrl+S 在 Linux/X11 上将统计截图复制到剪贴板时挂起的问题
- 修复 `/terminal-setup` 在 Windows Terminal 中显示矛盾错误信息的问题——Shift+Enter 在该终端中原生支持
- 修复 `/effort` 选择器未反映 `CLAUDE_CODE_EFFORT_LEVEL` 环境变量覆盖值的问题
- 修复 `/status` 对部分用户显示错误默认模型的问题
- 修复斜杠命令自动完成弹窗被限制在约 3–5 条可见命令，而非随终端高度缩放的问题
- 修复 statusline `context_window` token 计数反映累积会话总量而非当前上下文用量的问题
- 修复在未启用"Option as Meta"的 macOS 终端（iTerm2、Terminal.app 默认）中 Alt+T（思考切换）不工作的问题
- 修复在 Windows 上从 `claude agents` 后台会话重新打开后键盘输入无响应的问题
- 修复 stdio MCP server 向 stdout 写入非协议数据时内存无限增长（RSS 10GB+）的问题
- 修复连接成功但 `tools/list` 失败的 MCP server 静默显示 0 个工具的问题——现会重试一次并在 `/mcp` 中显示"connected · tools fetch failed"
- 修复未授权的 claude.ai MCP 连接器显示"failed"而非"needs auth"，以及 headless `-p` 模式重试非瞬态 4xx 连接失败的问题
- 修复 Bedrock 和 Vertex 在设置 `ENABLE_PROMPT_CACHING_1H` 时报 400 错误的问题

### 改进
- 改进了斜杠命令对话框和 `/login`、`/upgrade`、`/extra-usage` 对话框的视觉一致性
- 更新了 `/tui fullscreen` 启动横幅，描述了额外渲染器优势（更低内存占用、鼠标支持、选中自动复制）
