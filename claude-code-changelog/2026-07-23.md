## v2.1.218 — 2026-07-22

### 新功能 / 改进
- **`/code-review` 改为后台子 Agent 运行**：代码审查现在作为后台子 Agent 执行，不阻塞主会话
- **`/deep-research` 仅手动触发**：`/deep-research` 现在必须手动调用，不再自动运行
- **屏幕阅读器公告优化**：新增文件删除操作的屏幕阅读器公告

### Bug 修复
- **Windows 路径损坏修复**：修复 Windows 上 `\u` 前缀路径段被错误转换为 CJK 字符的问题
- **多行粘贴修复**：修复终端将换行编码为 Ctrl+J 时多行粘贴被折叠为一行的问题
- **崩溃防护**：修复监视目录树深度嵌套时删除/移动导致的崩溃问题
- **Auto 模式权限对话框优化**：改进 `dangerous-rm`、`background-&` 和可疑 Windows 路径检查的自动模式权限对话框
