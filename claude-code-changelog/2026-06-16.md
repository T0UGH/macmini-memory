# Claude Code Changelog — 2026-06-16

> 近 2 天共发布 3 个新版本：v2.1.178（6月15日）、v2.1.177（6月13日）、v2.1.176（6月12日）

---

## v2.1.178 — 2026-06-15

### 主要更新

- **权限规则支持 `Tool(param:value)` 语法**：新增 `Tool(param:value)` 匹配工具输入参数，支持 `*` 通配符，如 `Agent(model:opus)` 可屏蔽 Opus 子 agent。
- **嵌套 `.claude/skills` 目录支持**：在嵌套子目录中的 skills 现在会随文件加载，命名冲突时以 `<dir>:<name>` 形式区分。
- **Auto 模式子 agent 预检优化**：子 agent 启动前先经分类器评估，修复了此前子 agent 可绕过审查直接请求被屏蔽操作的漏洞。
- **`/doctor` 输出优化**：改为统一扁平树形布局，状态图标更清晰，命令名称高亮。
- **Remote Control 错误提示增强**：连接失败时底部显示红色 `"/rc failed"` 持续提示；未启用错误会说明是 gate、检查失败、过期授权还是组织策略问题。
- **`/bug` 命令加固**：现在强制要求描述内容，且不再用模型拒绝文本作为 GitHub Issue 标题。

### Bug 修复（15 项）

- 修复 CLI 因继承父进程遗留 websocket/OAuth 文件描述符环境变量而 OOM 崩溃
- 修复 Chrome 中 Claude 的 OAuth token 所属账号与 Claude Code 登录账号不一致导致的静默连接失败
- 修复非交互式运行中被嵌套 skills 错误触发权限提示的问题
- 修复子 agent 转录视图不显示工具结果和实时进度的问题
- 修复子 agent 轮次结束时发送的消息被丢弃的问题
- 修复 `Ctrl+B` 后台挂起不再从头重启子 agent
- 修复 `claude agents` 在设置了 `ANTHROPIC_BASE_URL` 和 `ANTHROPIC_AUTH_TOKEN` 时报 401 错误
- 修复上下文压缩忽略 `--fallback-model` 的问题，现正确回退到配置的备用模型链
- 修复外部刷新凭证后模型请求持续失败的问题
- 修复后台会话在 turn 结束后显示 "Working" 永远不变的问题
- 修复 marketplace 插件安装时 `CLAUDE_CODE_PLUGIN_KEEP_MARKETPLACE_ON_FAILURE=1` 阻止全新安装的问题
- 修复子 agent `disallowedTools` 中 `mcp__server`、`mcp__server__*`、`mcp__*` 被静默忽略的问题
- 修复 vim 模式 `u` 命令不逐条撤销而是合并连续命令的问题
- 修复 `claude agents` 中状态行链接（如 `vscode://`）点击无响应的问题
- 修复 Esc 取消 CJK IME 候选窗口时同时取消运行中任务的问题

## v2.1.176 — 2026-06-12

### 主要更新

- **会话标题本地化**：会话标题现在使用对话语言生成，可通过 `language` 设置固定语言。
- **Footer 链接徽章正则支持**：新增 `footerLinksRegexes` 设置，支持通过正则匹配在底部状态栏显示链接徽章。
- **Bedrock 凭证缓存增强**：`awsCredentialExport` 凭证缓存时间从固定 1 小时改为按实际 `Expiration` 时间戳决定。

### Bug 修复（大量）

- **模型配置**：修复 `availableModels` 允许列表可通过环境变量被绕过的漏洞；修复 Fable 5 组织未启用 Opus 4.8 时 Auto 模式失败的问题
- **Hook 配置**：修复 `Edit(src/**)`、`Read(~/.ssh/**)`、`Read(.env)` 等文档化路径模式不匹配的问题
- **Linux 沙箱**：`~/.claude/settings.json` 为符号链接时启动失败的问题
- **剪贴板 & tmux**：修复 `/copy` 和鼠标选择复制内容无法到达系统剪贴板的问题；修复旧版 tmux（<3.2）粘贴缓冲失效的问题
- **Remote Control**：修复从 web/mobile 连接时静默切换会话模型的问题；修复断开通知显示纯数字错误码而非人类可读原因；修复连接失败重复添加会话记录的问题
- **目录 & Git**：修复 `/cd` 和 worktree 切换后仍显示旧目录 git 分支的问题
- **Agent & 会话**：修复 `claude agents` 中一个窗口按返回键导致其他窗口脱离的问题；修复后台会话挂起后永久显示 "Working" 的问题；修复后台 agent 按 PR URL 搜索无法找到scheduled wakeup期间创建的 PR 的问题
- **后台会话**：修复 Windows 网络路径持久化状态；修复损坏状态文件导致 resume ID 格式错误被拒绝的问题；修复 Windows `~/.claude/daemon` 设置了 ReadOnly 属性导致后台服务无法启动的问题
