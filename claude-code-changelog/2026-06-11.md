# Claude Code Changelog - 2026-06-11

## v2.1.173 (2026-06-11)

- **Fable 5 模型名修复**：自动去除 `[1m]` 后缀（Fable 5 已默认包含 1M 上下文）
- **Windows 沙盒警告修复**：消除启用沙盒时多余的"沙盒依赖缺失"启动警告

## v2.1.172 (2026-06-10)

- **子 Agent 可嵌套调用**：子 Agent 现可自行派生子 Agent（最多 5 层深度）
- **Bedrock AWS 区域读取**：Amazon Bedrock 支持从 `~/.aws` 配置文件读取区域
- **插件市场搜索栏**：新增插件浏览搜索功能
- **新增 OTEL 指标属性**：`claude_code.lines_of_code.count` 指标新增 `model` 属性
- **1M 上下文会话修复**：超出用量额度后永久卡住的问题已修复，现自动压缩回标准限制
- **多图对话错误修复**：修复多图场景中图片处理重复报错的问题
- **Bedrock 模型选择修复**：`/model` 选择器不再显示不可用的 Bedrock 模型
- **子 Agent 模型限制修复**：`availableModels` 限制现正确应用于子 Agent 模型覆盖
- **模型 ID 后缀去重**：修复 `ANTHROPIC_DEFAULT_OPUS_MODEL` 已含 `[1m]` 时出现 `[1M][1m]` 的问题
- **通配符域名匹配修复**：`WebFetch(domain:*.example.com)` 规则现正确匹配子域名
- **远程会话内存召回修复**：修复无法找到挂载的团队内存存储（`CLAUDE_MEMORY_STORES`）的问题
- **工作流验证优化**：`Date.now()` / `Math.random()` 不再触发验证拒绝
- **Windows 控制台鼠标追踪优化**：对不完全支持鼠标的控制台禁用鼠标追踪
- **长对话性能优化**：移除冗余消息标准化，提升性能
- **子 Agent 并行执行优化**：减少空闲 CPU 占用
- **用量策略拒绝消息优化**：非交互模式下给出更友好的提示

> 来源：https://github.com/anthropics/claude-code/releases
