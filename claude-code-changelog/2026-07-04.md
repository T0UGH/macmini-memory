## v2.1.200 — 2026-07-03

**发布日期：** 2026-07-03 16:52 UTC

**主要更新：**
- `AskUserQuestion` 对话框不再默认自动继续，可通过 `/config` 设置空闲超时
- 默认权限模式改为 "Manual"（CLI / VS Code / JetBrains 均已更新）
- 修复：禁用/启用 MCP 服务器配置为非数组值时启动崩溃
- 修复：后台会话在睡眠唤醒或重新打开卡住会话时静默中断
- 修复：子代理被速率限制切断且无任何输出时返回空结果 → 改为正确报错
- 修复：tmux 3.4+ 下渲染闪烁（启用同步终端输出）
- 改进：屏幕阅读器支持（装饰性符号隐藏、转录符号读为短标签、嵌套表格读为结构化行）
- 改进：安装脚本报错时提示系统内存不足的情况

## v2.1.199 — 2026-07-02

**发布日期：** 2026-07-02 23:35 UTC

**主要更新：**
- 子代理现在默认在后台运行（Gradual Rollout 完成）
- Claude in Chrome 正式 GA（全面可用）
- 新增 `/dataviz` 技能：图表和仪表盘设计指导 + 可运行配色验证器
- Gateway 新增 AWS 上的 Claude Platform（anthropicAws）上游提供商
- 后台代理完成代码工作后自动 commit、push 并打开 Draft PR（无需询问）
- 修复：网络瞬时中断不再中止 turn，改用 backoff 重试
- 修复：子代理被速率限制切断时静默失败 → 返回 partial work
- 修复：API 错误（如用量超限）不再被报告为成功结果
- 修复：后台代理守护进程在 Linux 上约每 50 秒因损坏的 worker 记录而自杀
- `CLAUDE_CODE_RETRY_WATCHDOG` 改进：非容量瞬时错误默认重试次数提升至 300，`CLAUDE_CODE_MAX_RETRIES` 上限解除（15→300）
- `claude agents` 行显示 PR 链接格式精简为 `#N`（去除冗余 "PR" 标签）
