# Claude Code Changelog — 2026-03-28

## v2.1.86（2026-03-27）

### 🆕 新功能

- **新增 `X-Claude-Code-Session-Id` 请求头**：方便代理层按会话聚合请求，无需解析请求体
- **新增 `.jj` / `.sl` 排除目录**：Grep 和文件自动补全不再进入 Jujutsu 或 Sapling 的元数据目录
- **Memory 文件名可点击**：保存 N 条记忆的通知中，文件名现在支持悬停高亮和点击打开
- **`/skills` 列表优化**：描述上限裁剪至 250 字符以节省上下文，按字母排序
- **Auto 模式提示优化**：被计划限制禁用时显示"unavailable for your plan"（而非"temporarily unavailable"）

### 🐛 Bug 修复

| 问题 | 说明 |
|------|------|
| `--resume` | 修复在 v2.1.85 之前创建的会话上失败的问题（报错 tool_use ids without tool_result blocks） |
| Write/Edit/Read | 修复在项目根目录外的文件（如 `~/.claude/CLAUDE.md`）上操作失败的问题 |
| 配置写入 | 修复每次 skill 调用都触发不必要磁盘写入的问题（可能导致性能问题和 Windows 配置损坏） |
| `/feedback` | 修复超长会话下可能 OOM 崩溃的问题 |
| `--bare` 模式 | 修复交互式会话中丢弃 MCP 工具和静默丢弃中途入队消息的问题 |
| OAuth 登录 | 修复 `c` 快捷键只复制约 20 字符而非完整 URL 的问题 |
| 状态栏 | 修复运行多个 Claude Code 实例时，状态栏显示其他会话模型的问题 |
| Read 工具 | 修复重复读取相同内容仍重新输出完整内容的问题（现使用紧凑行号格式并去重） |
| Marketplace 插件 | 修复 macOS/Linux 上官方脚本自 v2.1.83 起报"Permission denied"的问题 |
| 插件卸载对话框 | 修复按 `n` 后对话框行为不一致的问题 |
| 记忆文件渲染 | 修复 markdown/highlight 渲染缓存保留完整内容字符串导致内存增长的问题 |

### ⚡ 性能优化

- **减少启动时事件循环阻塞**：macOS keychain 缓存有效期从 5s 延长至 30s（利好大量 claude.ai MCP 连接器的用户）
- **减少 `@` 引用文件时的 token 开销**：原始字符串内容不再进行 JSON 转义
- **提升 Bedrock/Vertex/Foundry 用户的 prompt 缓存命中率**：从 tool 描述中移除了动态内容

### 🔌 VSCode 扩展修复

- 修复长时操作期间错误显示"Not responding"的问题
- 修复 Max 计划用户在 OAuth 令牌刷新后（登录 8 小时后）错误降级为 Sonnet 的问题
