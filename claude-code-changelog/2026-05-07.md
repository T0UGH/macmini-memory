## v2.1.132 — 2026-05-06

**发布类型：** 重大补丁版本（距上一版本 7 小时）

### 主要更新

**新增环境变量：**
- `CLAUDE_CODE_SESSION_ID`：Bash 子进程可访问当前会话 ID（与 hooks 传入的 `session_id` 一致）
- `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1`：禁用全屏交替屏幕渲染，使用终端原生滚动缓冲

**新增 UX：**
- Ctrl+V 粘贴图片时显示 "Pasting…" 底部提示

**Terminal / 全屏模式修复：**
- 修复 IDE 停止按钮 / `kill -INT` 无法优雅关闭会话的问题（终端模式现正常恢复并提示 `--resume`）
- 修复终端关闭或 SSH 断连时原生构建的未捕获异常
- 修复睡眠/唤醒后全屏模式显示空白的问题
- 修复 Cursor / VS Code 1.92–1.104 中鼠标滚轮滚动过快问题
- 修复 JetBrains IDE 2025.2 终端滚轮方向错误问题
- 修复 Alt+T（思维切换）在未启用 "Option as Meta" 的 macOS 终端不生效的问题

**Vim 模式修复：**
- 修复 NFD 分解型重音字符导致 vim 操作符文本损坏
- 修复 `Space` 在 NORMAL 模式下正确右移光标

**粘贴行为修复：**
- 修复以 `/` 开头的粘贴文本被静默吞掉或触发未知命令
- 修复粘贴时混入多余转义序列的问题

**MCP 相关修复：**
- 修复 stdio MCP 服务器向 stdout 写入非协议数据导致内存无限增长（10GB+）的问题
- 修复 `tools/list` 失败的 MCP 服务器静默显示 0 个工具的问题（现重试一次并显示 "connected · tools fetch failed"）
- 修复未授权 claude.ai MCP 连接器显示 "failed" 而非 "needs auth" 的问题

**其他修复：**
- `/effort` 选择器现正确反映 `CLAUDE_CODE_EFFORT_LEVEL` 环境变量覆盖
- `/status` 修复对部分用户显示错误默认模型的问题
- 修复状态栏 `context_window` token 计数显示历史累计而非当前上下文用量的问题
- 修复 `ENABLE_PROMPT_CACHING_1H` 设置下 Bedrock / Vertex 400 报错的问题
- 修复 `/usage` Ctrl+S 在 Linux/X11 下复制统计截图卡住的问题
- 修复 Windows 上 `claude agents` 后台会话重新打开时键盘无响应的问题

## v2.1.129 — 2026-05-06

**发布类型：** 功能更新版本（距上一版本 2 天）

### 主要更新

**插件系统：**
- 新增 `--plugin-url <url>` 参数：支持从 URL 直接拉取插件 `.zip` 压缩包
- `--plugin-dir` 现同时支持 `.zip` 压缩包和目录
- 插件清单：建议将 `themes` 和 `monitors` 声明在 `"experimental": { ... }` 下（原有写法仍兼容但会报警）

**历史记录改进：**
- Ctrl+R 历史搜索默认跨所有项目搜索（恢复 2.1.124 前行为），Ctrl+S 可缩窄到当前项目/会话

**Gateway / 模型发现：**
- `/v1/models` 端点模型发现现为可选功能，需设置 `CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY=1` 开启

**权限与安全：**
- `--dangerously-skip-permissions` 现可绕过 `.claude/`、`.git/`、`.vscode/`、Shell 配置等保护路径的提示（危险命令仍有安全兜底）
- **安全修复**：修复 `allowManagedDomainsOnly` / `allowManagedReadPathsOnly` 在高优先级配置源缺少 `sandbox` 块时被忽略的问题

**会话与上下文：**
- 修复 `/clear` 不重置终端标签页标题的问题
- 修复 `/context` 将 ASCII 可视化网格倾倒到对话中（每次浪费约 1.6k tokens）
- 修复粘贴超大图片（>2000px）导致会话中断的问题（现自动缩小并重试）
- 修复 1 小时 prompt 缓存 TTL 被静默降级到 5 分钟的问题

**认证修复：**
- 修复 OAuth 登录在 WSL2 / SSH / 容器等无法回调 localhost 时超时失败的问题（支持直接粘贴终端回调码）
- 修复从睡眠唤醒后并发凭证写入导致有效 refresh token 被清除的问题

**其他修复：**
- Windows：修复 >22KB 剪贴板内容无法写入的问题（同时不再在进程命令行参数中暴露复制内容）
- 修复 Claude.ai MCP 连接器在手动服务器卡在 needs-auth 状态时被错误压制的问题
- 修复日/韩/中文本在 Windows 无闪烁模式下显示乱码的问题
- 修复 `/plugin update` 无法检测 npm 源插件新版本的问题
