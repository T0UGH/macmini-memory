## v2.1.200
**发布日期：** 2026-07-03

### Breaking Changes
- `AskUserQuestion` 对话框默认不再自动继续；可通过 `/config` 选择开启空闲超时
- 默认权限模式在 CLI、`--help`、VS Code 和 JetBrains 中统一改为 "Manual"

### Bug Fixes
- 修复 `.claude.json` 中 `disabledMcpServers` 或 `enabledMcpServers` 设置为非数组值时启动崩溃
- 修复睡眠/唤醒或重新打开卡住会话后后台会话静默停止的问题
- 修复后台会话在 stall respawn 后重新运行已取消轮次的问题
- 修复后台 agent daemon 交接时旧版本夺权问题（现在通过内置时间戳判断构建新旧）
- 修复 rate limit 在产生任何输出前截断子 agent 时返回空结果而非干净失败的问题
- 修复 git worktree 中项目级插件无法正确加载的问题
- 修复 tmux 3.4+ 下渲染闪烁（启用同步终端输出）
- 修复语音听写无音频时显示误导性"语音连接失败"消息

### 无障碍改进
- 装饰性符号对屏幕阅读器隐藏
- 翻译符号读作简短标签
- 嵌套表格读作 `Header: value.` 行
- `/mcp` 服务器列表现在支持屏幕阅读器和放大镜焦点跟踪

### 其他改进
- 安装脚本现在会在被系统 OOM 杀死时给出说明
