## v2.1.133 — May 7, 2026

**类型：** Features + Bug Fixes

### 新功能
- 新增 `worktree.baseRef` 设置项（`fresh` | `head`），控制 `--worktree`、`EnterWorktree` 和 agent-isolation worktree 从 `origin/<default>` 还是本地 `HEAD` 创建分支。**注意：** 默认值 `fresh` 将 `EnterWorktree` 的基础改回 `origin/<default>`（自 2.1.128 起为本地 `HEAD`）—— 如需在新 worktree 中保留未推送提交，设置 `worktree.baseRef: "head"`
- 新增 `sandbox.bwrapPath` 和 `sandbox.socatPath` 托管设置（Linux/WSL），用于指定自定义 bubblewrap 和 socat 二进制文件位置
- 新增 `parentSettingsBehavior` 管理级键（`'first-wins' | 'merge'`），允许管理员将 SDK `managedSettings`（父级）选择加入策略合并
- Hooks 现在通过 `effort.level` JSON 输入字段和 `$CLAUDE_EFFORT` 环境变量接收活动 effort 级别，Bash 工具命令可读取 `$CLAUDE_EFFORT`
- 改进 focus mode 行为
- 改进内存使用：在内存压力下释放备用后台 worker

### Bug 修复
- 修复 refresh-token 竞争条件导致共享凭证被清除后所有并行会话卡在 401
- 修复 `Edit`/`Write` allow 规则作用域到驱动器根（`C:\`）或 POSIX `/` 时匹配错误、总是提示
- 修复历史或会话日志文件锁被时钟偏移或慢速磁盘破坏时未处理的拒绝（`ECOMPROMISED`）
- 修复 `HTTP(S)_PROXY` / `NO_PROXY` / mTLS 在整个 MCP OAuth 流程（包括发现、动态客户端注册、token 交换和刷新）中未被遵循
- 修复 Read/Write/Edit 在通过 `--add-dir` / SDK `additionalDirectories` 传入的映射网络驱动器上被拒绝
- 修复来自 claude.ai 的 Remote Control stop/interrupt 未完全取消 CLI 会话（与本地 Esc 不同），导致中断卡住的工具或提示后队列消息无法前进
- 修复一个会话中的 `/effort` 意外改变其他并发会话的 effort 级别，以及 IDE effort 变更可能被静默丢弃的相关问题
- 修复 subagent 无法通过 Skill 工具发现项目、用户或插件 skills
- `claude --help` 现在同时列出 `--remote-control` 和 `--remote-control-session-name-prefix`
- [VSCode] 修复扩展构建未打包 Claude 二进制文件时 `claudeCode.claudeProcessWrapper` 报"不支持的平台"错误
