## v2.1.219
**发布日期：** 2026-07-24

### 重大更新
- **新增 Claude Opus 5**（`claude-opus-5`），现为默认 Opus 模型 — 1M 上下文，Fast 模式 $10/$50 per Mtok

### 新功能
- 新增 `sandbox.network.strictAllowlist` 设置：对沙箱命令默认拒绝未列入白名单的 host，不再弹窗提示
- 新增 `DirectoryAdded` Hook：在 `/add-dir` 或 SDK `register_repo_root` 控制请求注册新工作目录后触发
- 新增 `mcp_server_errors` 字段至 headless stream-json 初始化事件，列出被配置验证跳过的 `--mcp-config` 条目
- 新增 `workflowSizeGuideline` 设置键，可从任意设置文件设置动态工作流大小指南
- 新增嵌套子 Agent 转发：深度 2+ 的子 Agent 在 `--forward-subagent-text` 启用时会出现在 stream-json 中
- 子 Agent 现可默认嵌套至深度 3（此前为 1）；可设 `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH=1` 禁用嵌套

### 修复
- 修复 `claude -p` 在 mid-stream API 错误时已生成内容丢失的问题
- 修复自托管 Runner 重启期间批准的权限在会话恢复后丢失的问题
- 修复 GNU screen 中复制选中内容打印 base64 而非复制内容的问题
- 修复 Vim 模式：空提示符下按 ← 从 NORMAL 模式返回 Agent 视图
- 修复屏幕阅读器模式每次按键重写整行而非回显字符的问题

### 变更
- 动态工作流默认改为 medium 大小（不超过 15 个 Agent）
- `/fast` 现适用于 Opus 5 和 Opus 4.8（移除了 Opus 4.7 的 fast 模式）
- `context: fork` 的 Skill 默认在后台运行，可通过 `background: false` 逐个退出
- 支持 `yes`/`no`/`on`/`off`/`1`/`0` 作为布尔值（大小写不敏感）
