## v2.1.166 — 2026-06-06

### 新功能

- **fallbackModel 配置**：新增 `fallbackModel` 设置项，支持配置最多 3 个备用模型，当前模型超载或不可用时按序尝试；`--fallback-model` 参数现已同步应用于交互式会话
- **MAX_THINKING_TOKENS=0**：`MAX_THINKING_TOKENS=0`、`--thinking disabled` 及各模型的 thinking 开关现在可禁用默认启用了 thinking 的模型的思考功能（第三方 provider 不变）
- **claude agents 改进**：在会话列表中输入 URL 现在可过滤出首个 prompt 包含该 URL 的会话
- **claude update 体验优化**：`claude update` 现在在下载前会先播报目标版本号，不再静默等待

### 安全加固

- **跨会话消息硬化**：`SendMessage` 从其他 Claude 会话转发的消息不再携带用户权限——接收方会拒绝转发的权限请求，且自动模式会屏蔽此类消息
- **Claude Code 重试机制**：在备用模型上遇到非预期的不可重试 API 错误时，Claude Code 现在会重试一次；认证错误、速率限制、请求大小及传输错误仍会立即暴露

### Bug 修复

- 修复了发送无法处理的图片时出现"image could not be processed"错误并额外消耗 token 的问题
- 修复了后端短暂中断期间 worker 注册失败导致远程会话永久卡死的问题
- 修复了 2026.1+ JetBrains IDE 终端（IntelliJ、PyCharm、WebStorm 等）中输出闪烁的问题
- 修复了使用 Kitty 键盘协议（WezTerm、Ghostty、kitty）的终端中 Shift+非 ASCII 字符（如 Shift+ä → Ä）被丢弃的问题
- 修复了 Windows 上 PowerShell 命令验证在被杀进程的子进程持有输出管道时偶尔长时间挂起的问题
- 修复了 macOS 上守护进程断开连接后孤立 `claude --bg-pty-host` 进程以 100% CPU 空转的问题
- 修复了切换 `/voice` 后语音模式需要重新 `/login` 才能清除过时认证检查的问题
- 修复了包含无效条目的托管设置静默禁用其余有效策略强制执行的问题
- 修复了托管设置 `allowedMcpServers`/`deniedMcpServers` 谓词在使用 `${VAR}` 引用时无法匹配的问题
- 修复了进入 git worktree 后崩溃循环的背景 agent 会话从 `claude agents` 重新打开时报"No conversation found"的问题
- 修复了 Ctrl+O 转录视图中思考文本在流式输出时被重复显示的问题
- 修复了 `/doctor` 在远程会话内运行时显示矛盾性"不在远程会话中"检查失败的问题
- 修复了 `claude agents` 调度和回复输入框中多行 prompt 光标卡在首行末尾的问题
- 修复了不支持 Unicode 的终端上任务列表中背景 agent 行之间出现空行的问题
