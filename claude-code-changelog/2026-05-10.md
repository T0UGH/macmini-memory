# Claude Code Changelog — 2026-05-10

## 近 2 天新版本（5月8日 - 5月9日）

### v2.1.138 — 2026-05-09
- **类型**：内部修复

### v2.1.137 — 2026-05-09
- **类型**：Bug 修复
- **内容**：修复 Windows 上扩展激活失败的问题

### v2.1.136 — 2026-05-08
- **类型**：大版本更新，包含多项新功能和 Bug 修复
- **新功能**：
  - 新增 `CLAUDE_CODE_ENABLE_FEEDBACK_SURVEY_FOR_OTEL` 环境变量，用于企业级 OpenTelemetry 反馈调查采集
  - 新增 `settings.autoMode.hard_deny` 配置，实现自动模式的无条件拦截规则
- **Bug 修复**：
  - 修复 MCP 服务器（`.mcp.json`、插件、claude.ai 连接器）在执行 `/clear` 后静默消失的问题
  - 修复并发凭证写入时覆盖轮换 OAuth Token 导致的罕见登录循环
  - 修复多个 MCP OAuth 服务器并发刷新时丢失刷新令牌的问题
  - 修复调用工具后发送扩展思考（extended thinking）时触发 400 错误并产生红块的问题
  - 修复项目路径含下划线时 `--resume`/`--continue` 无法找到会话的问题
  - 修复 Plan 模式在存在匹配的 `Edit(...)` 允许规则时未正确阻止文件写入的问题
  - WSL2：修复 Windows 剪贴板图片粘贴功能（通过 PowerShell 回退方案）
  - 修复插件钩子因缓存清理删除正在使用的版本而导致失败的问题
  - 修复 `/usage` 周重置显示时分秒而非日历日期的问题
  - 修复 `/insights` 在会话历史工具调用格式异常时崩溃的问题
  - 修复 `/mcp` 服务器列表滚动问题
  - 修复快捷键提示未反映 `keybindings.json` 中自定义绑定的问题
- **UI/UX 修复**：斜杠命令对话框、中文终端支持、色彩渲染等多项优化
