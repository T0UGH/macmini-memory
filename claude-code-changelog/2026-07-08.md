## v2.1.203 (2026-07-07)

**新功能：**
- 新增登录过期警告，防止后台会话意外中断
- 新增 Manual 权限模式指示器（灰色 ⏸ 徽章）
- MCP `roots/list` 支持：会话工作目录通过 MCP 暴露，支持变更通知
- VSCode 设置新增"Enable Remote Control for all sessions"开关

**重要修复（~30+ 修复中的重点）：**
- 修复 macOS 上 15–20 秒假死问题（误判低内存导致）
- 修复守护进程会话 token 过期导致永久无响应
- 修复工作目录被删除/替换时的崩溃循环
- 修复自动升级失败导致会话被静默杀死
- 修复子 agent 任务无法被正确找到
- 修复 Windows 后台 agent 继承过期 PATH
- 修复 `ANTHROPIC_BASE_URL` 丢失导致 401 错误
- 修复 git worktree 相关的"argument list too long"错误
- 修复子 agent 在错误目录（而非 worktree）执行命令

**性能改进：**
- 二进制文件体积减小约 **7MB**
- 启动内存减少约 **7MB**
- 修复上下文使用量指示器每轮对话重新分析全部记录的问题
- 优化流式响应期间的实时预览渲染

**行为变更：**
- 左箭头不再关闭后台任务/差异视图（改用 Esc）
- 移除了启动时的"claude command missing"警告（已移至 `/doctor`）
