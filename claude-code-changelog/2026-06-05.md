# Claude Code Changelog — 2026-06-05

## v2.1.165 — 2026-06-05

- Bug fixes and reliability improvements

## v2.1.163 — 2026-06-04

### 新功能
- 新增 `requiredMinimumVersion` 和 `requiredMaximumVersion` 管理设置：若 Claude Code 版本不在允许范围内将拒绝启动，并引导用户使用批准版本
- 新增 `/plugin list` 命令，可列出已安装插件，支持 `--enabled`/`--disabled` 过滤
- `/btw` 新增 "c to copy" 快捷键，可将原始 markdown 答案复制到剪贴板，保留格式
- Hooks：Stop 和 SubagentStop hooks 现在可返回 `hookSpecificOutput.additionalContext`，在不被标记为 hook 错误的情况下向 Claude 提供反馈并继续对话
- Skills：新增 `\$` 转义语法，可在命令正文中包含字面量 `$` 加数字
- stdio MCP servers 现在接收与 hooks/Bash 在 `--resume` 时相同的 `CLAUDE_CODE_SESSION_ID`

### Bug 修复
- 修复 `claude -p` 在后台命令未退出时永久挂起的问题（后台 shell 现在在 stdin 关闭约 5 秒后停止）
- 修复 `claude -p` 在 Bedrock/Vertex/Foundry 环境下 `CI=true` 且未设置 Anthropic API key 时报错的问题
- 修复 Bazel 和 EDR 保护的 Go 工作流中 Bash 命令失败问题（`$TMPDIR` 被错误覆盖为 `/tmp/claude-{uid}`，回归于 2.1.154）
- 修复 Windows 上 session-env 目录含只读属性或位于 OneDrive 内时 Bash 命令报错 "EEXIST"
- 修复管理权限规则在全新配置目录下启动时未完整生效的问题
- 修复 `claude agents` 后台会话在 Claude Code 更新后重新附加时丢失后台任务的问题
- 修复按 Esc 退出 agent view 时的终端错位和数秒卡顿
- 修复桌面应用后台任务 chip 上的 Stop 按钮在底层进程已消失时未清除 chip 的问题
- 修复粘贴操作后键盘输入永久无响应的问题（终端丢失 end marker 导致）
- 修复 hook `if: "Bash(...)"` 条件对所有含 `$()` 或 `$VAR` 的命令触发的问题，现正确匹配 subshell 和 backtick 内的命令
- 修复 `Read(~/Desktop/**)` 等主目录路径的拒绝规则未拦截通过 `$HOME` 引用的 Bash 命令的问题
- 修复关闭 `/mcp`、`/plugins` 等面板弹窗后遗留 "(no content)" 杂线的问题

### 改进
- 后台 agent 会话现可在后台更新到新版 Claude Code，更新后重新打开会话不再等待冷启动
- `/` 菜单中内置命令和 skill 的描述更清晰
- 订阅切换建议移至启动公告栏位，而非 toast 通知
- 从 state-grouped 视图启动 `claude agents` 现从打开 agent view 的目录启动
