# Claude Code Changelog — 2026-04-22

> 汇总 2026-04-18 至 2026-04-22 期间发布的版本。

---

## v2.1.117 — 2026-04-22 (今日)

**核心新功能**

- **Forked 子代理支持**：通过环境变量 `CLAUDE_CODE_FORK_SUBAGENT=1` 开启外部构建上的 Forked 子代理
- **Agent frontmatter MCP 服务器**：通过 `--agent` 启动的 main-thread 会话现在也加载 agent frontmatter 中的 `mcpServers`
- **模型选择持久化**：`/model` 的模型选择现在跨重启保持，即使项目指定了不同模型也会有提示
- **大会话摘要**：`/resume` 现在会自动提示对过期大会话进行摘要后再加载
- **并发 MCP 启动**：本地和 claude.ai MCP 服务器同时配置时现在并发连接，启动更快
- **Native builds 加速**：macOS/Linux 的 Glob/Grep 工具替换为内置 `bfs`/`ugrep`，通过 Bash 工具调用，减少工具往返
- **Pro/Max 默认 effort 升级**：Opus 4.6 / Sonnet 4.6 的默认 effort 从 `medium` 升为 `high`
- **清理策略扩展**：`cleanupPeriodDays` 现在也清理 `~/.claude/tasks/`、`~/.claude/shell-snapshots/`、`~/.claude/backups/`

**Bug 修复**

- 修复 Plain-CLI OAuth 会话 token 过期导致"Please run /login"的问题（现改为 reactive 刷新）
- 修复大 HTML 页面 `WebFetch` 挂起问题
- 修复代理返回 HTTP 204 时的崩溃
- 修复 `NO_PROXY` 在 Bun 下不被尊重的问题
- 修复 Opus 4.7 会话 `/context` 显示膨胀百分比及过早自动压缩的问题
- 修复 Windows `where.exe` 缓存

---

## v2.1.116 — 2026-04-20

**核心新功能**

- **大会话 /resume 加速**：40MB+ 会话提速最高 67%，死分支条目多的会话处理更高效
- **MCP 启动加速**：多 stdio 服务器配置时更快；`resources/templates/list` 延迟到首次 `@` 提及
- **全屏滚动优化**：VS Code / Cursor / Windsurf 终端滚动更平滑，`/terminal-setup` 现配置编辑器滚动灵敏度
- **思考提示词优化**：旋转进度提示改为内联文字（"still thinking" → "almost done thinking"）
- **设置搜索增强**：`/config` 搜索现在也匹配选项值（如搜索"vim"能找到 Editor mode）
- **Plugin 自动依赖解析**：`/reload-plugins` 和后台自动更新现在自动从已配置的 marketplace 安装缺失依赖
- **安全加固**：沙箱 auto-allow 不再绕过对 `rm`/`rmdir` 指向 `/`、`$HOME` 等关键目录的危险路径检查

**Bug 修复**

- 修复 Devanagari 等印度文字在终端列对齐错误
- 修复 iTerm2/Ghostty/kitty 等使用 Kitty 键盘协议终端的 Ctrl+Z 挂起问题
- 修复 `/branch` 拒绝 50MB+ 抄本会话
- 修复 `/update` 和 `/tui` 在 mid-session 进入 worktree 后不工作
