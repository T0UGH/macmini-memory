# Claude Code Changelog — 2026-06-12

## v2.1.175

**发布日期：** 2026-06-12

**主要更新：**
- 新增 `enforceAvailableModels` 托管设置 —— 启用后，`availableModels` 白名单也会约束 Default 模型（若 Default 解析到不允许的模型，将自动回退到白名单中第一个允许的模型），且用户或项目设置无法扩大托管 `availableModels` 列表的范围。

## v2.1.174

**发布日期：** 2026-06-12

**主要更新：**
- 新增 `wheelScrollAccelerationEnabled` 设置，可在全屏模式下禁用鼠标滚轮滚动加速
- 修复 `/model` 选择器隐藏 Default 解析目标模型家族的问题 —— Opus/Max/Sonnet 等现在正确显示为独立行
- 修复 `/model` 选择器在 `ANTHROPIC_DEFAULT_SONNET_MODEL` 固定不同 Sonnet 时仍显示硬编码 Sonnet 版本标签的问题
- 修复企业账户仍显示 "Fable 5 正在消耗使用额度" 横幅的问题
- 修复 Bedrock GovCloud 区域（`us-gov-*`）推导错误推理配置前缀（`global` 而非 `us-gov`）导致的 400 错误
- 修复后台会话从启动 shell 错误继承另一个会话的 `ANTHROPIC_*` provider 环境变量的问题
- 修复在 macOS 和 Linux 上中断/kill shell 命令后退出 Claude Code 出现 1-2 秒暂停的问题
- 修复 git commit co-author 信息对部分模型显示错误模型名的问题
- 修复 `/advisor` 对话框预选了被 `availableModels` 白名单阻止的 advisor 模型的问题
- 修复技能热重载时重复发送完整技能列表的问题 —— 现在仅重新通知已更改的技能
- 修复 Workflow tool `agent()` 子代理缺少每代理归属请求头的问题
- **（VSCode）** `/usage` 对话框新增使用量归因，展示近 24 小时/7 天的缓存未命中、长上下文、子代理及按技能/代理/MCP 分项明细
- 修复空闲后被认领的预热后台 worker 因 "无法解析认证方法" 而失败的问题
