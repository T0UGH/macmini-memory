## v2.1.176 (2026-06-12)

### 新功能
- **会话标题多语言生成**：会话标题现在会根据对话语言自动生成（可设置 `language` 固定语言）
- **页脚链接正则匹配**：新增 `footerLinksRegexes` 设置，支持在页脚行配置正则匹配链接徽章

### 改进
- **Bedrock 凭证缓存优化**：从 `awsCredentialExport` 获取的凭证现在缓存至其 `Expiration` 时间，而非固定 1 小时
- **模型限制强化**：`availableModels` 白名单现在阻止通过 `ANTHROPIC_DEFAULT_*_MODEL` 环境变量绕道， `/fast` 在切换到白名单外的模型时会拒绝执行
- **自动模式兼容性修复**：对未启用 Opus 4.8 的组织，自动模式现回退到最佳可用 Opus 模型

### Bug 修复
- 修复了 Read/Edit/Write 工具路径上 hook `if` 条件对文档化模式（如 `Edit(src/**)`）的匹配问题
- 修复了 `.claude/settings.json` 为指向绝对路径的符号链接时 Linux 沙箱启动失败
- 修复了 SSH + tmux 环境下 `/copy` 及鼠标复制无法写入系统剪贴板的问题
- 修复了远程控制会话从 web/mobile 连接时静默切换模型的问题
- 修复了远程控制断开通知显示裸数字代码、连接失败时对话记录重复行的问题
- 修复了 `/cd` 和 worktree 移动后会话仍显示旧目录 git 分支的问题
- 修复了 `claude agents` 中按 PR URL 搜索时，定时唤醒或任务阻塞期间创建的 PR 搜索不到的问题
- 修复了 Windows 上 agents 视图输入框无光标的问题
- 修复了 `claude --bg -cn <name>` 未正确设置会话名称的问题
- 修复了 Windows 后台会话在 `~/.claude/daemon` 设置 ReadOnly 属性后无法启动守护进程的问题
- 修复了云会话空闲过久后被认领时报 "Could not resolve authentication method" 的问题
- 后台会话在跨自动更新无法提交回复时显示更清晰的引导，`claude daemon status` 解释了版本偏移行为
