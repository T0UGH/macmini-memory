## v2.1.206 — 2026-07-10（今日发布）

### 新功能
- **目录路径建议**：`/cd` 现在支持类似 `/add-dir` 的路径补全建议
- **`/doctor` 检查 CLAUDE.md 精简**：自动提示可以删除 Claude 可从代码库自动推导的内容
- **`/commit-push-pr` Git 推送优化**：自动允许推送到 `remote.pushDefault` 或唯一配置的远程仓库
- **Gateway `/login` 支持**：新增对 Anthropic 公共 Gateway 端点的登录支持
- **`EnterWorktree` 确认提示**：进入 `.claude/worktrees/` 外的 git worktree 前增加确认
- **后台 Agent 自动升级**：Claude Code 更新后，后台运行的 Agent 在后台自动升级到新版本

### Bug 修复
- 修复登录过期时错误提示为"模型选择问题"的问题，改为正确提示运行 `/login`
- 修复 `--resume`/`--continue` 启动时忽略键盘输入的问题
- 修复 `--mcp-config`/`.mcp.json` 忽略各 MCP Server `request_timeout_ms` 配置的问题
- 修复 `CLAUDE_CODE_EXTRA_BODY` 在后台 worker 中被静默忽略的问题
- 修复 OAuth MCP 令牌刷新失败一次后就需要手动重新认证的问题
- 修复冷启动时 `--permission-prompt-tool` 因 MCP 服务器未连接而崩溃的问题
- 修复 `/model` 选择器中价格显示错误的问题
- 修复桌面会话在斜杠命令中途时卡在"running"状态的问题
- 修复 Windows 上 `claude --resume` 时 setup prompt 遮盖 agents view 键盘输入的问题
- 修复 `claude rm` 移除任务后 daemon roster 未更新导致任务重复出现的问题
- 修复 Bedrock 在受限网络下使用 `awsCredentialExport` 导致长时间挂起的问题
- 大量其他 UI 和稳定性修复

### 改进
- **代码审查质量**：提升 `/code-review` 在 claude-opus-4-8 各难度级别下的发现质量
- **Agents 视图**：状态列现在使用完整终端宽度，不再截断在 64 字符处

## v2.1.205 — 2026-07-08

### 新功能
- **Auto Mode 安全改进**：执行 `rm -rf` 前，如果变量无法从上下文解析，会主动询问确认
- **内存效率优化**：自动更新下载改为流式写入磁盘，峰值内存减少约 400 MB
- **后台通知改进**：后台任务通知现在明确说明"未发生人工输入"，防止伪造审批记录
- **Agent 视图 PR 关联**：编辑、合并、评论或推送 PR 的会话现在会在 `claude agents` 中关联显示
- **Agent 视图标题优化**：行内显示彩色状态词 + AI 生成的标题摘要，不再是原始工具调用文本
- **新版 `/doctor` 命令**：升级为完整的安装体检工具，支持诊断和修复问题，`/checkup` 为别名
- **MCP 服务名保留**：保留 "Claude Browser" MCP 服务名（与 "Claude Preview" 并列）

### Bug 修复
- 修复自动模式下篡改会话记录文件的问题（新增自动模式规则拦截）
- 修复无效 JSON Schema 导致静默输出无结构数据的问题
- 修复 `--max-turns` 限制时正在处理的消息被静默丢失的问题
- 修复 Windows worktree 删除时误删符号链接外文件的问题
- 修复后台 Agent 用 `SendMessage` 恢复后状态仍显示"失败/完成"的问题
- 修复 `claude attach` 在后台 Agent 升级重启时出错的问题
- 修复 MCP Desktop 导入时服务器名含特殊字符导致卡住的问题
- 修复 LSP 插件服务器初始化失败阻止同扩展名其他 LSP 服务器工作的问题
- 修复 Windows 启动目录被删除/锁定时崩溃的问题
- 修复文件监视器在目录扫描进行中关闭时崩溃的问题
