# Claude Code Changelog — 2026-07-22

> 来源：https://github.com/anthropics/claude-code/releases

---

## v2.1.217 — 2026-07-21

**7 个新功能 · 13 个 Bug 修复**

### 新功能
- **Emoji 短代码自动补全**：输入 `:heart:` 自动补全为 ❤️，可通过 `emojiCompletionEnabled` 配置
- **子 Agent 并发数限制**：默认上限 20，可通过 `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS` 配置
- **子 Agent 嵌套控制**：子 Agent 默认不再生成嵌套子 Agent，可通过 `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` 配置深度
- **超链接支持增强**：SSH/tmux 环境下页脚 PR 链接现也可点击，可通过 `FORCE_HYPERLINK=0` 禁用
- **登录过期预警提前**：从提前 5 天改为提前 3 天
- **前端设计建议提示限制**：最多展示 3 次

### Bug 修复
- **内存泄漏修复**：截断的 MCP 工具输出不再在内存中保留完整未截断结果
- **Windows 自动更新修复**：更新失败后自动恢复保留的可执行文件，避免 `claude.exe` 丢失
- **启动 OOM 防护**：`CLAUDE.md`/`SKILL.md` 括号展开现以预算为上限
- **后台会话隔离**：符号链接工作目录现进行规范化，防止工作区逃逸
- **MCP 设置**：企业 mTLS、TLS 验证、OAuth scope 和代理设置现已在 Claude Desktop 会话中生效
- **遥测端点修复**：`OTEL_EXPORTER_OTLP_ENDPOINT` 现统一管理所有信号
- **屏幕阅读器模式**：启动公告不再被截断，思考状态行不再频繁重新渲染
- **`/resume` 修复**：不再因格式错误的附件条目报 TypeError
- **`--max-budget-usd`**：现正确停止运行中的后台子 Agent
- **Auto-compact**：现正确触发 Claude Opus 4.8 on Bedrock

## v2.1.216 — 2026-07-20

### 新功能
- **`sandbox.filesystem.disabled` 配置项**：跳过文件系统隔离的同时保留网络出口控制

### Bug 修复
- **性能修复**：修复长会话中消息规范化的二次方增长问题（多轮对话后出现数秒卡顿）
- **云会话恢复修复**：会话容器在 turn 中重启时，中断的 turn 现可重新运行
- **OAuth 修复**：修复 Token 过期后自动模式报 "HTTP 401" 分类错误、Claude-in-Chrome 403 重连循环、MCP 重新认证先撤销凭证的问题
- **后台 Agent 会话恢复**：修复恢复后台 Agent 会话时回退为默认 Agent（现已恢复 agent prompt 和工具限制）
- **Git 安全**：修复 worktree 隔离子 Agent 通过 `git -C`、`--git-dir`、`GIT_WORK_TREE`/`GIT_DIR` 重定向到共享仓库的问题
- **UI 修复**：修复 Esc-Esc 在有后台任务的空闲提示符下无法打开回退选择器、`/memory` 不再等待编辑器关闭、全屏模式下对话框拉伸问题、RTL 文本（阿拉伯语、希伯来语）渲染顺序
- **Bash 命令解析**：修复重定向在 `&&` 列表中的权限检查、非 ASCII 字符的 shell 词边界解析、PowerShell 中含不可见 Unicode 字符的命令验证
- **遥测修复**：修复 Prometheus 指标端点输出无效 `# UNIT` 行、权限拒绝误报

### 改进
- **`/fork`**：确认提示现显示新会话名称、`claude attach` ID 及是否共享 checkout
- **`/context`**：对话超出上下文窗口时现显示明确警告
- **`/rewind`**：不再通过符号链接或硬链接恢复/删除文件
- **`/ultrareview`**：diff 过大错误现显示配置的限额、实际 diff 大小及最大贡献文件
- **后台会话**：`/mcp` 和 `/install-github-app` 现可在无客户端连接时在 agent 视图中显示"需要输入"请求
