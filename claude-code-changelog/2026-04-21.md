# Claude Code Changelog — 2026-04-21

> 汇总日期：2026-04-21（覆盖近 2 天内发布的新版本）

## v2.1.116 — 2026-04-20

**核心新特性：**

- **`/resume` 大幅提速**：40MB+ 会话提速最高 67%，对大量死分支条目处理更高效
- **MCP 启动更快**：多个 stdio 服务器配置时启动更快，`resources/templates/list` 改为首次 `@` 提及时才加载
- **终端滚动更顺滑**：VS Code / Cursor / Windsurf 终端滚动体验优化，`/terminal-setup` 现可配置编辑器滚动灵敏度
- **思考动画更直观**：思考旋转动画现内联显示进度文字（"still thinking" → "almost done"），替代原有提示行
- **`/config` 搜索增强**：现已匹配选项值（如搜索 "vim" 可找到编辑器模式设置）
- **`/doctor` 响应中可打开**：Claude 响应期间无需等待即可运行 `/doctor`
- **`/reload-plugins` 自动补依赖**：插件重载及后台自动更新时，自动安装已添加 marketplace 中的缺失依赖
- **`gh` 命令限流提示**：Bash 工具现会在 `gh` 命令触发 GitHub API 限流时给出提示，避免无效重试

**安全修复：**

- 沙箱白名单不再绕过 `rm`/`rmdir` 针对 `/`、`$HOME` 等关键系统目录的危险路径检查

**Bug 修复（16 项）：**

- 修复 Devanagari 等印度文字在终端列对齐异常的问题
- 修复 iTerm2 / Ghostty / kitty / WezTerm / Windows Terminal 下 Ctrl+- 无法撤销的问题
- 修复 Warp 全屏 / kitty / Ghostty / WezTerm 下 Cmd+Left/Right 无法跳转到行首/行尾的问题
- 修复通过 `npx`/`bun run` 等封装进程启动时 Ctrl+Z 挂起终端的问题
- 修复内联模式下终端调整大小或大输出时滚动历史重复的问题
- 修复短终端高度下模态搜索框溢出屏幕的问题
- 修复 VS Code 集成终端滚动时空白单元格和 composer 元素消失的问题
- 修复并行请求完成时偶发的 API 400 错误（与缓存 TTL 顺序有关）
- 修复 `/branch` 拒绝 50MB 以上会话的问题
- 修复 `/resume` 大会话文件静默显示空会话的问题（现报告加载错误）
- 修复 `/plugin` 已安装选项卡中同一项目重复显示的问题
- 修复会话中途进入 worktree 后 `/update` 和 `/tui` 无法使用的问题
