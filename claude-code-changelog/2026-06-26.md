## 近 2 天新版本（2026-06-25 ~ 2026-06-26）

### v2.1.193 — 2026-06-25

**发布时间：** 21:45 UTC

**新增功能：**
- 新增 `autoMode.classifyAllShell` 配置项，可将所有 Bash/PowerShell 命令路由至 auto-mode 分类器
- auto-mode 拒绝原因现在会显示在 transcript、toast 和 `/permissions` 的最近拒绝列表中
- 新增 `claude_code.assistant_response` OpenTelemetry 日志事件（默认跟随 `OTEL_LOG_USER_PROMPTS`）
- Bash 模式下新增实时文件路径自动补全（`!` 触发）
- MCP 服务器需要认证时，启动时新增提示指引

**改进：**
- 沙盒网络权限对话框：已允许的 hosts 会在会话期间自动记住
- MCP OAuth：瞬态网络错误会重试一次
- 流式响应期间 CPU 使用率降低约 **37%**
- 减少了长会话的内存增长

**Bug 修复：**
- 修复 `/model` 在 `/login` 后显示陈旧/空状态的问题
- 修复了后台 agent 停止后意外复活的问题
- 修复了睡眠唤醒后流式请求失败的问题
