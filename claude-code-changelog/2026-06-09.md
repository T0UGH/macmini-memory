# Claude Code Changelog — 2026-06-09

## v2.1.169 (2026-06-08)

> 近 2 天内发布

### 新功能

- **`--safe-mode` 标志**：新增 `--safe-mode` 启动参数及 `CLAUDE_CODE_SAFE_MODE` 环境变量，以纯净模式启动 Claude Code，禁用所有自定义项（CLAUDE.md、插件、skills、hooks、MCP servers），方便排查问题。
- **`/cd` 命令**：新增会话内切换工作目录命令，切换时不破坏提示缓存（prompt cache）。
- **`disableBundledSkills` 配置**：新增 `disableBundledSkills` 设置项及 `CLAUDE_CODE_DISABLE_BUNDLED_SKILLS` 环境变量，可隐藏内置 skills、工作流和内置斜杠命令，减少模型干扰。

### Bug 修复

- 修复上/下方向键遍历长命令历史时跳行问题，现在按视觉行逐行移动，历史回溯从近端边缘进入。
- 修复企业托管 MCP 策略（`allowedMcpServers` / `deniedMcpServers`）在重连后未正确生效的问题。
