# Claude Code Changelog — 2026-04-30

## v2.1.123 — 2026-04-29（今日最新）

**修复**
- 修复了在设置 `CLAUDE_CODE_DISABLE_EXPERIMENTAL_BETAS=1` 时 OAuth 认证失败并进入 401 重试循环的问题

---

## v2.1.122 — 2026-04-28

**新增**
- 新增 `ANTHROPIC_BEDROCK_SERVICE_TIER` 环境变量，支持选择 Bedrock 服务层级（`default`、`flex` 或 `priority`），以 `X-Amzn-Bedrock-Service-Tier` 请求头发送
- 在 `/resume` 搜索框中粘贴 PR URL，现在可以找到创建该 PR 的会话（支持 GitHub、GitHub Enterprise、GitLab、Bitbucket）

**修复**
- 修复 `/model` 对 Bedrock 应用推理配置 ARN 不显示 Effort 选项的问题
- 修复发送给新模型的图片被错误缩放至 2576px 而非最大 2000px 的问题
- 修复远程控制会话空闲状态每秒重绘两次的问题

---

## v2.1.121 — 2026-04-28

**新增**
- MCP 服务配置新增 `alwaysLoad` 选项——设为 `true` 时，所有工具跳过 tool-search 延迟加载
- 新增 `claude plugin prune` 命令，清理孤立（orphan）的自动安装插件依赖
- `/skills` 新增类型过滤搜索框

**修复**
- 修复会话中处理大量图片时内存无限增长的问题
- 修复 `/usage` 在有大量 transcript 历史记录的机器上泄漏约 2GB 内存的问题
- 修复 Bash 工具在会话中途工作目录被删除/移动后永久不可用的问题
