## v2.1.178 — 2026-06-15

**新功能（5 项）：**
- `Tool(param:value)` 语法：支持按工具输入参数匹配权限规则（含 `*` 通配符），如 `Agent(model:opus)` 阻止 Opus 子 agent
- 嵌套 `.claude/skills` 目录中的 skills 现在在对应目录下工作时自动加载；命名冲突时以 `<目录>:<名称>` 呈现
- 嵌套 `.claude/` 目录：agent/workflow/output-style 优先匹配最近的工作目录；项目级 workflow 保存到最近存在的 `.claude/workflows/`
- 改善 Auto 模式：子 agent 启动前经 classifier 评估，堵住子 agent 可绕过审查请求被阻止操作的漏洞
- 改善 `/doctor`：统一扁平树布局、清晰状态图标、高亮命令名称

**修复类（13 项）：**
- 修复父进程遗留 WebSocket/OAuth fd 环境变量导致 OOM 崩溃
- 修复 Chrome 中 Claude 在 OAuth token 与登录账号不匹配时静默连接失败
- 修复嵌套 skills 目录-qualified 名称在非交互运行时被权限提示阻止
- 修复子 agent：查看 transcript 现显示工具结果和实时进度；turn 结束期间发送的消息不再丢失；Ctrl+B 后台化不再从头重启
- 修复 `claude agents` worker 在 daemon 由含自定义 API gateway 的 shell 启动时报 `401 Invalid bearer token`
- 修复 compaction 不遵循 `--fallback-model`：现可在超载或模型不可用时正确降级
- 修复外部刷新凭证后请求仍报认证错误的缓存问题
- 修复 `/bg` 或 `←←` 创建的后台会话在 turn 结束后永久显示 "Working"
- 修复 Linux sandbox 在 `.claude/skills` 或 `.claude/hooks` 为符号链接时启动失败
- 修复 `CLAUDE_CODE_PLUGIN_KEEP_MARKETPLACE_ON_FAILURE=1` 阻止 marketplace 新安装克隆
- 修复子 agent `disallowedTools` 中的 MCP server 级别 spec 被静默忽略
- 修复 vim 模式 `u` 撤销行为（快速连续命令不再合并为单次撤销）
- 修复 `claude agents` 中自定义 URI scheme 状态行链接无法点击打开
