# Claude Code Changelog — 2026-03-11

## v2.1.72（2026-03-10 发布）

### 新功能

- **`/copy` 增强**：新增 `w` 键可将选中内容直接写入文件（SSH 场景下绕过剪贴板）
- **`/plan` 增强**：支持描述参数，如 `/plan fix the auth bug`，直接进入计划模式并开始规划
- **ExitWorktree 工具**：新增退出 worktree 会话的工具
- **Bash 自动批准扩展**：新增 `lsof`、`pgrep`、`tput`、`ss`、`fd`、`fdfind` 到白名单，减少权限弹窗
- **`CLAUDE_CODE_DISABLE_CRON`**：新增环境变量可立即停止定时任务
- **`plugin` 别名**：`claude plugins` 作为 `claude plugin` 的别名
- **Agent 工具 `model` 参数**：恢复了 Agent 工具的 per-invocation 模型覆盖能力
- **Git URL 支持**：支持不带 `.git` 后缀的 marketplace git URL（Azure DevOps、AWS CodeCommit）
- **VS Code URI Handler**：新增 `vscode://anthropic.claude-code/open` 打开新 Claude Code 标签页
- **语音输入改进**：提升对仓库名称和常见开发术语（regex、OAuth、JSON）的转录准确率

### 体验优化

- **Effort 等级简化**：从 4 级简化为 3 级（low/medium/high），新图标 ○ ◐ ●，`/effort auto` 重置
- **`/config` 改进**：Escape 取消、Enter 保存、Space 切换
- **History 导航**：多会话并行时优先显示当前会话消息
- **CLAUDE.md HTML 注释**：自动注入时隐藏 HTML 注释，Read 工具读取时仍可见
- **包体积减小**：减少约 510 KB
- **Bash 命令解析**：切换到原生模块，启动更快，消除内存泄漏
- **减少误报权限弹窗**：Tree-sitter 解析改进，支持 `find -exec`、变量赋值、命令替换等
- **Prompt Cache 优化**：修复 SDK `query()` 调用中的缓存失效问题，输入 token 成本最高降低 12 倍

### Bug 修复（重点）

- 修复慢退出（后台任务/hooks 响应慢时）
- 修复 Agent 任务进度卡在 "Initializing…"
- 修复 skill hooks 触发两次
- 修复语音模式多个问题：输入延迟、误报 "No speech detected"、提交后旧转录重填
- 修复 `--continue` 在 `--compact` 后不恢复最近位置
- 修复 Windows 插件安装在 OneDrive 文件夹失败（EEXIST 错误）
- 修复 `--effort` CLI 标志在启动时被重置
- 修复 Ctrl+B 后台查询丢失 transcript
- 修复 `/clear` 误杀后台 agent/bash 任务
- 修复并行工具调用中 Read/WebFetch/Glob 失败会取消兄弟任务（现仅 Bash 错误级联）
- 修复 U+2028/U+2029 字符导致 Desktop/SDK 崩溃
- 修复恢复包含 Bedrock API 错误的会话时崩溃
- 修复权限规则匹配多个边界情况（heredocs、换行、env var 前缀等）
- 修复 "Always Allow" 保存永远无法再匹配的规则
