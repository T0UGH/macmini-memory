# Claude Code Changelog — 2026-05-15

> 监测周期：2026-05-13 ~ 2026-05-15，汇总近 2 天内发布的新版本。

---

## v2.1.142

**发布日期：** 2026-05-14

**主要更新：**

- `claude agents` 新增多个配置 flag：`--add-dir`、`--settings`、`--mcp-config`、`--plugin-dir`、`--permission-mode`、`--model`、`--effort`、`--dangerously-skip-permissions`，用于配置派发的后台会话
- Fast mode 默认模型升级为 Opus 4.7（之前是 Opus 4.6）；可通过 `CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE=1` 锁定 Opus 4.6
- 根目录有 `SKILL.md` 且无 `skills/` 子目录的插件现在也会作为 skill 暴露
- `/plugin` 详情面板和 `claude plugin details` 现在会显示插件提供的 LSP 服务器
- `/web-setup` 在替换已有 GitHub App 连接时会发出警告
- 修复 `MCP_TOOL_TIMEOUT` 对远程 HTTP/SSE MCP 服务器不生效的 bug（之前工具调用上限被锁定为 60 秒）
- 修复 macOS 睡眠唤醒后后台会话消失、daemon 重连失败的问题（现在 daemon 会检测时钟跳跃）
- 修复 daemon 在二进制升级后未正常退出的问题（之前会导致派发的 agents 崩溃循环）
- 修复 Windows 网络驱动器工作目录下 `claude agents` 死锁问题
- 优化 reactive compaction：首次摘要尝试现在会从原始请求的溢出大小播种，避免浪费一次接近满上下文的重试
- 改进 hook 配置错误提示：若为 `SessionStart`/`Setup`/`SubagentStart` 配置了 prompt- 或 agent-type hook，现在会明确提示"请改用 command-type hook"

---

## v2.1.141

**发布日期：** 2026-05-13

**主要更新：**

- 新增 `terminalSequence` 字段到 hook JSON 输出，支持无控制终端时发送桌面通知、窗口标题和提示音
- 新增 `CLAUDE_CODE_PLUGIN_PREFER_HTTPS` 环境变量，优先使用 HTTPS 克隆 GitHub 插件源（适用于无 SSH key 的环境）
- 新增 `ANTHROPIC_WORKSPACE_ID` 环境变量，支持工作负载身份联合——当联合规则覆盖多个 workspace 时，可将令牌限定到特定 workspace
- `claude agents --cwd <path>` 将会话列表限定到指定目录
- `/feedback` 现可附上近期会话（最近 24 小时或 7 天），方便提交跨会话问题
- Rewind 菜单新增"压缩至此"选项，可在保留近期对话的同时压缩早期上下文
- 自动模式权限对话框现在会说明是哪个 `permissions.ask` 规则触发了该提示
- `/model claude-sonnet-4-20250514` 错误建议已从使用策略拒绝消息中移除
- 大量 bug 修复：涉及 VSCode 语音反馈、Windows daemon 错误展示、权限模式切换、Ctrl+C 中断、多行状态栏渲染等多个场景
