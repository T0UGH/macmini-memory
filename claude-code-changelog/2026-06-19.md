# Claude Code Changelog — 2026-06-19

## v2.1.183 — 2026-06-19

**⭐ 今日最新版本（Latest）**

### 主要更新

- **🛡️ Auto Mode 安全增强**：未主动要求时，自动拦截破坏性 Git 命令（`git reset --hard`、`git checkout -- .`、`git clean -fd`、`git stash drop`），并拦截 `git commit --amend`（非本 Session 代理提交的 commit）、`terraform destroy` / `pulumi destroy` / `cdk destroy`（非指定具体栈）
- **⚠️ 弃用模型警告**：请求的模型已弃用或自动切换到新模型时，在 stderr 中显示警告（print 模式和 agent frontmatter 均支持）
- **🔗 attribution.sessionUrl**：新增配置项，可在 Web 和 Remote Control Session 中隐藏 commit/PR 中的 claude.ai session 链接
- **📋 /config --help**：新增帮助命令，列出所有 `/config key=value` 的可用快捷键
- **🔧 /config 交互改进**：Enter 和 Space 均可切换设置项，Esc 现在保存并退出而非还原

### Bug 修复

- 修复 `thinking.disabled.display` 在子 agent 和 session-title 生成时报 400 错误
- 修复子 agent 中 WebSearch 返回空结果的问题
- 修复 Windows Terminal 在高并发嵌套 subagent 负载下 TUI 损坏的问题
- 修复模型仅返回 thinking block 时 turn 无声完成的问题（现重新提示一次）
- 修复多个插件启用时用户级 skills 在斜杠命令自动完成中重复出现的问题
- 修复 tmux teammate 面板 shell 初始化慢时指令泄漏到新 tmux 窗格的问题
- 修复 teammate 启动的后台任务在 teammate 完成本轮后被误杀的问题
- 修复定时任务/webhook 触发被错误识别为键盘输入的问题

## v2.1.181 — 2026-06-17

### 主要更新

- **⚡ /config key=value**：可直接在提示词中设置任意配置项（如 `/config thinking=false`），支持交互模式、`-p` 模式和 Remote Control
- **🍎 sandbox.allowAppleEvents**：新增 opt-in 设置，允许沙盒命令在 macOS 上发送 Apple Events（修复 error -600）
- **📱 CLAUDE_CLIENT_PRESENCE_FILE**：通过标记文件抑制移动端推送通知，人在电脑前时可屏蔽通知打扰
- **📦 升级 Bun 运行时**：内置 Bun 升级到 1.4 版本
- **⚡ 流式输出优化**：长段落文本逐行显示，无需等待第一个换行符
- **🔄 改进自动重试**：thinking 期间 API 连接中断现在自动重试，不再显示 "Connection closed while thinking"
- **📊 Subagent 面板优化**：空闲 subagent 30 秒后自动隐藏，列表最多 5 行+滚动提示，底部显示键盘快捷键

### Bug 修复

- 修复自定义 `ANTHROPIC_BASE_URL` 和 Foundry 上 prompt 缓存读取失败的问题
- 修复 Write/Edit 在网络驱动器/云同步文件夹上写入 0 字节或截断文件的问题
- 修复 macOS 上 auth 流程报 error -600 的问题（新增 Apple Events entitlement）
- 修复 v2.1.169 引入的冷启动回归（约 120ms 延迟）
- 修复启动时网络慢导致黑屏长达 15 秒的问题
- 修复 `.claude.json` 含损坏 null 项目条目时启动崩溃
- 修复 Spotlight 重索引时 macOS TUI 冻结（Ctrl+C 无响应）问题
- 修复长时间空闲 Session 在另一个 Claude Code 进程运行 30 天清理时丢失历史记录
- 修复大量其他 UI、API 和跨平台稳定性问题（共计 40+ 项修复）
