# Claude Code Changelog — 2026-05-12

## v2.1.139 — 2026-05-11

**发布类型：** 大版本更新

### 主要新功能

- **Agent View（Research Preview）** — 单列表视图，展示所有 Claude Code 会话（运行中、等待中、已完成）。通过 `claude agents` 访问
- **`/goal` 命令** — 设置完成条件，Claude 跨轮次持续工作直到达成目标。支持交互式、`-p` 和 Remote Control 模式，实时显示已用时间/轮次/token
- **`/scroll-speed` 命令** — 调节鼠标滚轮滚动速度，带实时预览
- **`claude plugin details <name>`** — 显示插件的组件清单和每会话预估 token 费用
- **Transcript 视图导航** — `?` 显示键盘快捷键，`{`/`}` 跳转用户提示，`v` 切换快捷键面板

### 改进

- Hook `args: string[]` 字段（exec 形式）— 无需 shell，直接执行命令，路径占位符无需引号
- Hook `continueOnBlock` 配置选项（PostToolUse）— 将拒绝原因反馈给 Claude 并继续当前轮次
- MCP stdio 服务器现在接收 `CLAUDE_PROJECT_DIR` 环境变量
- Subagent API 请求现在携带 `x-claude-code-agent-id` / `x-claude-code-parent-agent-id` 请求头
- Remote Control、`/schedule`、claude.ai MCP 连接器和通知偏好设置现已在设置 API key 环境变量时被禁用

### Bug 修复（30+ 项）

- 修复了 `claude auth` 命令在凭证过期时的死锁问题
- 修复了 `autoAllowBashIfSandboxed` 无法自动批准含 shell 展开（`$VAR`, `$(cmd)`）命令的问题
- 修复了 hook 输出到终端导致交互式提示符损坏的问题
- 修复了 HTTP/SSE MCP 服务器在流式传输非协议数据时内存无限增长的问题
- 修复了 `Skill(name *)` 通配符权限规则（现支持前缀匹配）
- 修复了符号链接 `~/.claude/settings.json` 的热重载问题
- 修复了响应完成后 5 分钟触发 "stream idle timeout" 的问题
- [VSCode] 新增 Cmd/Ctrl+Shift+T 快捷键，重新打开最近关闭的会话标签页
