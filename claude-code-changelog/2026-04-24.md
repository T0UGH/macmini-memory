# Claude Code Changelog — 2026-04-24

## v2.1.119（2026-04-23）

**配置与持久化**
- `/config` 设置（主题、编辑器模式、verbose 等）现在持久化到 `~/.claude/settings.json`，并参与项目/本地/策略覆盖优先级
- 新增 `prUrlTemplate` 设置项，可自定义底部 PR 徽章指向的代码评审 URL（而非默认 github.com）
- 新增 `CLAUDE_CODE_HIDE_CWD` 环境变量，可在启动 Logo 中隐藏工作目录

**平台与协议支持**
- `--from-pr` 现已支持 GitLab Merge Request、Bitbucket Pull Request 及 GitHub Enterprise PR URL
- `--print` 模式现在遵循 Agent 的 `tools:` 和 `disallowedTools:` frontmatter，与交互模式行为一致
- `--agent <name>` 现已遵循内置 Agent 定义的 `permissionMode`
- PowerShell 工具命令现在支持在 permission 模式下自动批准（与 Bash 行为一致）

**Hook 与插件**
- Hooks：`PostToolUse` 和 `PostToolUseFailure` hook 输入现在包含 `duration_ms`（工具执行时间，不含 permission 提示和 PreToolUse hooks）
- 插件依赖：通过另一插件版本约束固定的插件现在自动更新到满足约束的最高 git tag
- Hooks 现在可直接调用 MCP 工具（`type: "mcp_tool"`）

**UI/UX 改进**
- Vim 模式：INSERT 模式下按 Esc 不再将队列中的消息拉回输入区；再按一次 Esc 才中断
- 斜杠命令建议现在高亮匹配查询的字符
- 斜杠命令选择器现在将长描述换行到第二行，而非截断
- 输出中的 `owner/repo#N` 简写链接现在使用 git remote 的 host，不再始终指向 github.com

**安全与可观测性**
- 安全：`blockedMarketplaces` 现已正确强制执行 `hostPattern` 和 `pathPattern` 条目
- OpenTelemetry：`tool_result` 和 `tool_decision` 事件现在包含 `tool_use_id`；`tool_result` 还包含 `tool_input_size_bytes`
- 状态栏：stdin JSON 现包含 `effort.level` 和 `thinking.enabled`

**Bug 修复（38 项）**
- 修复粘贴 CRLF 内容（Windows 剪贴板、Xcode 控制台）在每行间插入多余空行
- 修复 kitty 键盘协议下多行粘贴丢失换行符
- 修复原生 macOS/Linux 构建中禁用 Bash 工具后 Glob/Grep 工具消失
- 修复全屏模式下向上滚动时工具完成会跳回底部
- 修复 MCP HTTP 连接返回非 JSON body 时报 "Invalid OAuth error response"
- 修复 Rewind 叠加层在图片附件消息上显示 "(no prompt)"
- 修复 MCP OAuth client secret 未在 token exchange 时发送（`client_secret_post` 场景）
- 修复 `--from-pr` / `--print` / `/agents` 等多处细节问题

## v2.1.118（2026-04-23）

**Vim 模式**
- 新增 Vim 可视模式（`v`）和可视行模式（`V`），支持选择、操作符和视觉反馈

**主题与配置**
- 合并 `/cost` 和 `/stats` 为 `/usage`（两者仍作为快捷键可用）
- 从 `/theme` 创建和切换自定义命名主题，或手动编辑 `~/.claude/themes/` 下的 JSON 文件
- 插件也可通过 `themes/` 目录发布主题
- 新增 `DISABLE_UPDATES` 环境变量，可完全阻止所有更新路径（含手动 `claude update`），比 `DISABLE_AUTOUPDATER` 更严格

**WSL 与平台**
- WSL on Windows 现可通过 `wslInheritsWindowsSettings` 策略键继承 Windows 侧托管设置
- Auto mode：可在 `autoMode.allow`、`autoMode.soft_deny` 或 `autoMode.environment` 中包含 `"$defaults"`，在内置列表基础上添加自定义规则（而非替换）
- 新增 auto mode 提示中的"不再询问"选项

**插件系统**
- 新增 `claude plugin tag` 命令，可为插件创建 release git tag（含版本校验）
- `--continue`/`--resume` 现在可以找到通过 `/add-dir` 添加当前目录的会话
- 插件依赖错误现在提示"not installed"并给出安装提示

**UI/UX 改进**
- `/color` 现在同步会话强调色到 claude.ai/code（Remote Control 连接时）
- `/model` 选择器现在支持自定义 `ANTHROPIC_BASE_URL` 网关的模型覆盖
- Advisor Tool（实验性）现已标记"实验性"标签和启动通知，修复了会话卡住错误

**可观测性**
- OpenTelemetry：`user_prompt` 事件现包含 `command_name` 和 `command_source`；`cost.usage` / `token.usage` / `api_request` / `api_error` 现包含 effort 属性

**性能**
- macOS/Linux 原生构建：Glob/Grep 工具替换为内置 `bfs` 和 `ugrep`，通过 Bash 工具调用——搜索更快，无需单独的工具往返（Windows 和 npm 安装版不变）
- Windows：缓存 `where.exe` 可执行文件查找，减少子进程启动开销

**Bug 修复（30+ 项）**
- 修复 MCP OAuth token 无 `expires_in` 时每小时要求重新认证
- 修复 MCP OAuth refresh 在无跨进程锁的情况下执行导致竞态
- 修复 macOS keychain 竞态导致意外 "Please run /login" 提示
- 修复 OAuth token 在本地过期时间前被服务端撤销导致 refresh 失败
- 修复 Linux/Windows 凭证保存崩溃导致 `~/.claude/.credentials.json` 损坏
- 修复 Alt+K / Alt+X / Alt+^ / Alt+_ 冻结键盘输入
- 修复 VSCode 语音听写首次录音在权限提示期间无输出
