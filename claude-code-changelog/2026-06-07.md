### v2.1.166
- **日期：** 2026-06-06
- **更新内容：**
  - **新增 `fallbackModel` 配置项：** 可设置最多 3 个备用模型，按顺序在主模型超载或不可用时自动切换；`--fallback-model` 现也适用于交互式会话
  - **deny 规则支持 glob 通配符：** `"*"` 可拒绝所有工具，未知工具名会在启动时警告
  - **跨会话消息加固：** 通过 `SendMessage` 转发的消息不再携带用户权限，接收方拒绝权限请求，自动模式也加以阻止
  - **禁用 thinking token：** `MAX_THINKING_TOKENS=0`、`--thinking disabled` 或模型配置可禁用默认启用 thinking 的模型
  - **API 错误重试机制：** 非重试类 API 错误会在备用模型上重试一次（认证、限流、请求大小、传输错误仍即时暴露）
  - **`claude update` 改进：** 下载前会先提示目标版本号
  - **`claude agents` 改进：** 输入 URL 可过滤到包含该 URL 的会话
  - **多项 Bug 修复：**
    - 修复不可处理图片导致的"image could not be processed"错误及额外 token 消耗
    - 修复后端短暂中断时远程会话永久卡死的问题
    - 修复 JetBrains IDE 终端（2026.1+）闪烁问题
    - 修复 Kitty 键盘协议终端（WezTerm、Ghostty、kitty）Shift+非 ASCII 字符丢失
    - 修复 PowerShell 命令验证在 Windows 上偶尔超时
    - 修复 macOS 上 daemon 断开后后台 PTY 进程空转 100% CPU
    - 修复 voice mode 切换后需重新登录的认证问题
    - 修复托管设置无效条目静默禁用其他策略的问题
    - 修复 git worktree 后台会话 crash-loop 无法恢复的问题
    - 修复 Ctrl+O  transcript 视图中 thinking 内容重复显示
    - 修复 `/doctor` 在远程会话中显示矛盾结果
    - 修复 `claude agents` 多行输入框光标定位问题
    - 修复无 Unicode 支持终端的背景任务行间距问题
