# Claude Code Changelog — 2026-03-10

## v2.1.72（2026-03-10）

### 新功能
- `/copy` 新增 `w` 键，可直接将选中内容写入文件（SSH 场景下无需依赖剪贴板）
- `/plan` 支持描述参数，如 `/plan fix the auth bug`，直接进入计划模式并开始
- 新增 `ExitWorktree` 工具，可退出 `EnterWorktree` 会话
- 新增 `CLAUDE_CODE_DISABLE_CRON` 环境变量，可立即停止会话内的定时任务
- `lsof`、`pgrep`、`tput`、`ss`、`fd`、`fdfind` 加入 bash 自动批准白名单
- Agent 工具恢复 `model` 参数，支持按调用指定模型
- 简化 effort 等级为 low/medium/high（移除 max），图标改为 ○ ◐ ●
- 支持无 `.git` 后缀的 marketplace Git URL（Azure DevOps、AWS CodeCommit）
- `claude plugins` 作为 `claude plugin` 的别名

### 改进
- `/config` 操作优化：Escape 取消、Enter 保存/关闭、Space 切换
- 上箭头历史记录优先显示当前会话消息
- 语音转录准确性提升（repo 名称、regex、OAuth、JSON 等开发术语）
- Bash 命令解析改用原生模块，更快启动、无内存泄漏
- tree-sitter 解析增强，减少 bash 权限误判
- 包体积减少约 510 KB
- CLAUDE.md HTML 注释在自动注入时对 Claude 隐藏

### Bug 修复（重点）
- 修复后台任务/hooks 缓慢导致退出变慢
- 修复 agent 任务进度卡在 "Initializing…"
- 修复 skill hooks 每事件触发两次
- 修复多个语音模式问题（输入延迟、误报"No speech detected"、过期转录）
- 修复 `--continue` 在 `--compact` 后无法恢复
- 修复多个插件问题（Windows EEXIST 错误、marketplace 作用域冲突等）
- 修复 SDK `query()` 调用中 prompt cache 失效（最高减少 12x 输入 token 成本）
- 修复 Escape 键在取消查询后无响应
- 修复团队 agent 未继承 leader 的模型
- 修复文件内容含 U+2028/U+2029 字符导致会话崩溃
- 修复并行工具调用的级联失败问题
- 修复多个权限规则匹配问题
- VSCode 专项修复：滚动速度、Shift+Enter 行为、effort 指示器、URI handler
