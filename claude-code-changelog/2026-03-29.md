## v2.1.86 — 2026-03-27

**主要更新：**

- **API 新增 Header**：新增 `X-Claude-Code-Session-Id` header，代理可按会话聚合请求
- **VCS 排除列表**：`.jj`（Jujutsu）和 `.sl`（Sapling）加入 VCS 目录排除列表，Grep 和文件自动完成不再进入这些目录
- **修复 /resume 崩溃**：修复了从 v2.1.85 之前创建的会话使用 `--resume` 时报 "tool_use ids were found without tool_result blocks" 的问题
- **修复越根目录编辑**：修复了配置了条件 skills 或规则时，Write/Edit/Read 无法操作项目根目录外文件（如 `~/.claude/CLAUDE.md`）的问题
- **修复性能问题**：修复了每次 skill 调用时不必要的配置磁盘写入，避免 Windows 上的性能问题和配置损坏
- **修复 /feedback 内存问题**：修复了在超长会话中使用 `/feedback` 时可能因大型 transcript 文件导致内存溢出的问题
- **修复 --bare 模式**：修复了 `--bare` 模式下交互会话中丢弃 MCP 工具的问题
- **修复 OAuth URL 复制**：修复了 `c` 快捷键仅复制约 20 字符 OAuth 登录 URL 的问题
- **修复 marketplace 脚本权限**：修复了自 v2.1.83 以来官方 marketplace 插件脚本在 macOS/Linux 上报 "Permission denied" 的问题
- **修复状态栏模型显示**：修复了多实例运行时在其中一个使用 `/model` 导致状态栏显示错误会话模型的问题
- **性能优化**：macOS keychain 缓存时间从 5s 延长至 30s，减少了大量 claude.ai MCP 连接器配置时的启动事件循环卡顿
- **Token 优化**：通过移除动态内容提高 Bedrock、Vertex、Foundry 用户的 prompt 缓存命中率
- **Token 优化**：`@` 提及时不再对原始字符串内容进行 JSON 转义，减少 token 开销
- **UX 改进**：内存文件名在 "Saved N memories" 提示中支持悬停高亮和点击打开
- **UX 改进**：`/skills` 列表中的技能描述限制为 250 字符，减少上下文占用
- **UX 改进**：`/skills` 菜单改为字母序排列，方便查找
- **UX 改进**：Auto 模式现显示 "unavailable for your plan"（按计划禁用）而非 "temporarily unavailable"
- **[VSCode]** 修复了长时间运行操作期间扩展错误显示 "Not responding" 的问题
- **[VSCode]** 修复了 Max plan 用户在 OAuth 令牌刷新（登录 8 小时后）后错误回退到 Sonnet 的问题
- **[VSCode]** Read 工具现使用紧凑行号格式，并对未变更的重新读取去重，减少 token 使用
