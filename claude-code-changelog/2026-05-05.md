# Claude Code Changelog — 2026-05-05

## v2.1.128
**发布日期：** 2026-05-04

### 主要更新

- **新增 `/color` 随机配色**：不带参数执行 `/color` 现在会随机选择会话颜色
- **MCP 服务器工具统计**：`/mcp` 现显示已连接服务器的工具数量，并标记零工具服务器
- **支持 `.zip` 插件包**：`--plugin-dir` 现在接受 `.zip` 格式的插件压缩包
- **Console 认证支持 `--channels`**：managed settings 的 Console org 需设置 `channelsEnabled: true`
- **模型选择器优化**：折叠重复的 Opus 4.7 条目，当前 Opus 显示为 "Opus" 而非 "Opus 4.7"
- **OTEL 环境变量隔离**：子进程不再继承 `OTEL_*` 变量，避免第三方 OTEL 应用误连 CLI 的 OTLP 端点
- **MCP `workspace` 保留名**：已使用该名称的服务器将被跳过并警告
- **MCP 重连优化**：重连不再每次刷屏显示完整工具列表，改为按服务器前缀汇总
- **SDK Hosts 持久化权限建议**：`localSettings` 建议 "Always allow" 写入 `.claude/settings.local.json`
- **`EnterWorktree` 行为修复**：从本地 HEAD 而非 `origin/<default-branch>` 创建分支，避免未推送提交丢失

### Bug 修复

- 修复 Focus 模式提交新提示时短暂变暗的问题
- 修复 Kitty 等终端每次 `/exit` 出现 "4;0;" 桌面通知（OSC 9 误触发）
- 修复 Remote Control 遇到限流时显示空消息而非可操作的引导
- 修复大文件（>10MB）通过 stdin 传给 `claude -p` 导致的崩溃循环
- 修复长 URL 在全屏模式下只有第一行可点击的问题
- 修复 MCP 工具结果同时返回结构化内容和 content blocks 时图片丢失
- 修复列表项内代码块复制粘贴时带前导空格
- 修复 `/config` 标签导航焦点丢失问题
- 修复 1M context 模型在小 autocompact window 下误报 "Prompt is too long"
- 修复并行 Bash 工具中只读命令失败会取消兄弟调用的问题
- 修复无 OSC 8 支持的终端上 markdown 链接标签丢失，改为显示 `label (url)`
- 修复 vim 模式下 `Space` 不移动光标的问题（改为向右移动，与标准 vi 行为一致）
- 修复 `CLAUDE_CODE_SHELL_PREFIX` 设置时 MCP stdio 服务器收到损坏参数（包含空格/metachar 的参数）
- 修复子 agent 进度摘要丢失 prompt cache 导致 3 倍 `cache_creation` 问题
- 修复空闲子 agent 重复触发摘要导致 token 浪费
- 修复 `--plugin-dir` 加载失败未包含在 `init.plugin_errors` 中（stream-json 输出）
