## v2.1.136 — 2026-05-08
- **新增** `CLAUDE_CODE_ENABLE_FEEDBACK_SURVEY_FOR_OTEL`：重新启用企业版会话质量调查，支持通过 OpenTelemetry 收集反馈
- **新增** `settings.autoMode.hard_deny`：Auto Mode 分类规则，强制无条件拒绝用户意图，不受 allow 例外影响
- **修复** `.mcp.json`、插件和 claude.ai 连接器配置的 MCP 服务器在执行 `/clear` 后静默消失的问题（VS Code、JetBrains、Agent SDK 均受影响）
- **修复** 并发凭证写入导致新轮换的 OAuth Token 被覆盖，引发罕见登录循环
- **修复** 多服务器并发刷新时 MCP OAuth 刷新令牌丢失
- **修复** Extended Thinking 在工具调用后发出 redacted thinking block 时 API 返回 400 错误
- **修复** 项目路径含下划线时 `--resume` / `--continue` 无法找到会话
- **修复** Plan Mode 中存在匹配的 `Edit(...)` allow 规则时未能正确阻止文件写入
- **WSL2** 改进：Windows 剪贴板图片粘贴现通过 PowerShell fallback 实现（xclip/wl-paste 无法读取时）
- **修复** 插件 `Stop` / `UserPromptSubmit` hook 在缓存清理删除运行中会话仍使用的版本时失败
- **改进** 斜杠命令对话框视觉一致性
- 以及其他多项终端渲染、MCP、插件系统、快捷键和对话框修复
