# Claude Code Changelog — 2026-06-03

> 近 2 天共发布 2 个新版本，以下按版本号从新到旧排列。

---

## v2.1.161 — 2026-06-02

**核心更新：**

- **OpenTelemetry 指标维度扩展**：`OTEL_RESOURCE_ATTRIBUTES` 的自定义标签（如 team、repo）现在会附加到用量指标的每个数据点上，支持更细粒度的用量分析
- **`claude agents` 进度展示优化**：fan-out 场景下显示 `done/total` 计数，`peek` 高亮最长运行时间项
- **MCP 面板折叠未登录连接器**：`/mcp` 页面将从未登录的 claude.ai 连接器折叠到"Show unused connectors"中
- **并行 Tool 调用解耦**：同一批次的并行 Tool 调用（如 Bash）中，一个失败不再取消其他调用，各自独立返回结果
- **全屏模式剪贴板优化**：Linux 下优先使用 `wl-copy`/`xclip`/`xsel`，并同时写入 PRIMARY 选择区方便中键粘贴
- **无障碍修复**：`/effort` 对话框、动效、关键词微光效果现在正确遵循"减少动画"系统设置
- **修复**：第三方提供商（Bedrock/Vertex/Foundry）的会话不再被 `forceLoginOrgUUID`/`forceLoginMethod` 策略意外拦截
- **修复**：`claude -p --output-format text/json` 与后台子 agent 输出混用导致 stdout 损坏的问题
- **修复**：`/usage-credits` 对 Team/Enterprise 管理员不再触发重新登录，直接跳转组织用量页面
- **修复**：`/autofix-pr` 在 git worktree 或其他仓库内正确识别非默认分支
- **修复**：`--resume` 选择器在非 git worktree 目录（如 jj workspace）正确显示当前目录的会话
- **修复**：Windows 上显式调用 bash 的钩子脚本不再报"command not found"
- **修复**：渲染性能 JIT 配置文件稳定性提升，大文件写入渲染速度改善
- **[VSCode]** 增加提示引导用户关闭终端 GPU 加速以解决字符乱码

## v2.1.160 — 2026-06-02

**核心更新：**

- **Shell 启动文件写入保护**：写入 `.zshenv`、`.zlogin`、`.bash_login` 及 `~/.config/git/` 前增加明确确认提示，防止意外命令执行
- **`acceptEdits` 模式安全加固**：对 `.npmrc`、`.yarnrc*`、`bunfig.toml`、`.bazelrc`、`.pre-commit-config.yaml`、`.devcontainer/` 等构建工具配置文件写入前增加提示
- **编辑权限简化**：`grep`/`egrep`/`fgrep` 单文件查询后可直接 `Edit`，无需单独 `Read`
- **Windows 剪贴板修复**：WSL 下 copy-on-select 正确写入 Windows 剪贴板（改用 PowerShell 替代 OSC 52）
- **后台会话稳定性**：修复会话恢复后聊天记录丢失、`claude --bg` 冷启动偶发 socket 错误、Windows 删除目录后残留进程锁等多项问题
- **性能优化**：减少 auto mode 推理开销以降低分类延迟；`claude agents` 列表退出时不再反复触发自动更新检查
- **信号处理改进**：后台会话销毁（`claude rm`/`stop`）现在先发送 SIGTERM 再 SIGKILL，确保清理处理器运行
- **触发词重命名**：`workflow` 关键词改为 `ultracode`，`workflow` 不再直接触发，但自然语言请求仍然有效
- **清理废弃变量**：`CLAUDE_CODE_OPUS_4_6_FAST_MODE_OVERRIDE` 环境变量已移除（现为无操作 no-op）
- **JetBrains 插件引导移除**：启动时不再提示安装 JetBrains 插件
