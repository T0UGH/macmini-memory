# Claude Code Changelog — 2026-05-13

> 今日（2026-05-13）汇总了近 2 天内发布的 2 个新版本。

---

## v2.1.140 — 2026-05-12

**类型：** Bug 修复 + 小改进

### 主要更新

- **Agent 工具 `subagent_type` 匹配增强**：支持大小写和分隔符不敏感的匹配（如 `"Code Reviewer"` → `code-reviewer`）
- **Agent 配色方案更新**
- **修复 `/goal` 命令静默挂起**：当设置 `disableAllHooks` 或 `allowManagedHooksOnly` 时，`/goal` 不再卡死
- **修复设置热重载回归**：符号链接的设置文件不再触发虚假 `ConfigChange` hooks
- **修复 `claude --bg` 连接错误**：后台服务即将空闲退出时的 "connection dropped mid-request" 错误
- **Windows 事件循环稳定性**：缺失 `gh` 等可执行文件时不再卡死
- **Read 工具参数验证修复**：`offset` 为空格或 `+` 前缀字符串时不再验证失败
- **插件警告增强**：组件文件夹被静默忽略时发出警告（显示在 `/doctor`、`claude plugin list`）

**修复数量：** 11 项 bug 修复 + 2 项功能改进

---

## v2.1.139 — 2026-05-11

**类型：** 大版本功能更新

### 主要新功能

- **Agent View（Research Preview）**：单一列表展示所有 Claude Code 会话（运行中、等待中、已完成），运行 `claude agents` 启动
- **新增 `/goal` 命令**：设置完成条件，Claude 跨轮次持续工作直到达成目标，支持交互模式、`-p` 和远程控制，显示实时耗时/轮次/token 统计
- **新增 `/scroll-speed` 命令**：调整鼠标滚轮滚动速度，带实时预览
- **新增 `claude plugin details <name>`**：显示插件组件清单和每会话预估 token 消耗
- **Transcript 视图导航**：`?` 显示快捷键，`{`/`}` 跳转用户提示
- **Hook 系统增强**：新增 `continueOnBlock` 配置，拒绝原因可反馈给 Claude 并继续回合
- **MCP 服务器改进**：stdio 服务器现接收 `CLAUDE_PROJECT_DIR`；远程 MCP 重连重试现已对所有用户启用
- **[VSCode]** `Cmd/Ctrl+Shift+T` 重新打开最近关闭的会话标签页

### 主要 Bug 修复

- 修复凭据过期时 `claude auth` 命令死锁
- 修复 HTTP/SSE MCP 服务器流式传输导致的无限内存增长（限制 16 MB/帧）
- 修复响应完成后虚假 "stream idle timeout" 警告
- 修复暗色主题超链接显示深蓝不可见
- 修复 CJK/emoji 字符边框溢出
- 修复 10+ MCP 服务器配置时静默 `exit 1`（错误信息现包含根本原因）

**修复数量：** 大量 bug 修复 + 多个新功能
