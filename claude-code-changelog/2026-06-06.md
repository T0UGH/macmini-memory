## v2.1.166

- **发布日期：** 2026-06-06
- **类型：** 功能更新版
- **主要更新：**

### 新功能
- **`fallbackModel` 配置项：** 可配置最多 3 个备用模型，当主模型超载或不可用时按顺序自动切换；`--fallback-model` 现在也适用于交互会话
- **deny 规则支持 glob 模式：** tool-name 位置支持 `*` 通配符（`"*"` 拒绝所有工具）；allow 规则拒绝非 MCP 的 glob，未知工具名在 deny 规则中会发出启动警告
- **跨会话消息安全加固：** 通过 `SendMessage` 转发的消息不再携带用户权限——接收方拒绝 relayed 权限请求，auto mode 也会阻止
- **`MAX_THINKING_TOKENS=0` / `--thinking disabled`：** 现在可以禁用默认会思考的模型的思考机制（第三方 provider 除外）
- **备用模型自动重试：** API 返回意外不可重试错误时，会在备用模型上重试一次；认证、速率限制、请求大小和传输错误仍立即报错
- **`claude update` 改进：** 下载前会宣布目标版本，不再静默
- **`claude agents` URL 过滤：** 在列表中输入 URL 现在可以过滤到首次 prompt 包含该 URL 的会话
