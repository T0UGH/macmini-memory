## v2.1.219 (2026-07-24)

### 新功能

| 功能 | 说明 |
|------|------|
| **Claude Opus 5** | 新增 `claude-opus-5`，作为默认 Opus 模型，支持 1M context，fast 模式 $10/$50/Mtok |
| **`sandbox.network.strictAllowlist`** | 新增设置项，对沙箱命令直接拒绝未列入白名单的 host，无需弹窗确认 |
| **`DirectoryAdded` hook** | 在 `/add-dir` 或 SDK `register_repo_root` 注册新工作目录时触发 |
| **子代理嵌套转发** | 深度 ≥2 的子代理可通过 `--forward-subagent-text` 出现在 stream-json 中 |
| **`/model` 选择器高亮** | 现在高亮显示最新模型的名称，便于发现新版本 |
| **工作流大小显示在状态栏** | 当前默认工作流大小现在显示在运行中工作流状态栏中 |
| **`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`** | 新环境变量，控制子代理嵌套深度（默认 3，设为 1 可禁用嵌套） |

### Bug 修复

- 修复 `claude -p` 文本输出在 API 中 stream 错误时丢失已生成答案的问题
- 修复自托管 runner 重启期间授予的权限在会话恢复后丢失的问题
- 修复 Fable 模型缓存中 "Requires usage credits" 标签因缓存过期而持续显示的问题
- 修复 GNU screen 中复制选中内容时打印 base64 而非真正复制的问题
- 修复屏幕阅读器模式下每次按键重写整个输入行的问题（现改为仅回显输入字符）

### 行为变更

- **Dynamic workflow 默认大小**：从 large 改为 **medium**（目标不超过 15 个 agent）
- **Opus 4.7**：从 fast 模式移除；`/fast` 现在应用于 Opus 5 和 Opus 4.8
- **子代理嵌套深度**：默认从 1 改为 3
