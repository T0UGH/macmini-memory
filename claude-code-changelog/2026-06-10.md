# Claude Code Changelog — 2026-06-10

## v2.1.170
**发布日期：** 2026-06-09

**主要更新：**
- 🚀 引入 **Claude Fable 5**：Anthropic 的 Mythos 级模型，现已全面开放，Fable 的能力超越 Anthropic 以往所有对外开放的模型
- 🐛 修复从 VS Code 集成终端或继承了 Claude Code 环境变量的 shell 启动时，sessions 不保存 transcript（且不出现在 `--resume` 中）的 bug

---

## v2.1.169
**发布日期：** 2026-06-08

**主要更新：**
- 🔧 **新增 `post-session` 生命周期钩子**：session 结束后、工作区删除前执行，支持快照未提交的工作或导出日志；同时 child-process 的 SIGTERM→SIGKILL 窗口现已可配置（默认仍为 5s）
- 🛡️ **新增 `--safe-mode` 标志**（`CLAUDE_CODE_SAFE_MODE`）：以无任何自定义配置（CLAUDE.md、插件、skills、hooks、MCP servers）模式启动，用于故障排查
- 📁 **新增 `/cd` 命令**：在不清除 prompt cache 的情况下将 session 切换到新工作目录
- ⚙️ **新增 `disableBundledSkills` 设置**：隐藏内置 skills、workflows 和 slash commands
- 🖥️ **企业级 MCP 策略**（`allowedMcpServers`/`deniedMcpServers`）修复：修复了在重连、IDE 类型配置、`--mcp-config` 服务器首次安装后 session 未生效的问题
- ⌨️ 修复 Up/Down 方向键在长命令换行时跳过多行的问题
- 📊 修复 macOS 上每次回复开始时有 ~30-50ms UI 卡顿的问题
- 🌐 修复 Windows 上 `claude -p` 慢或卡死的问题
- 🔄 修复远程控制 session 在 OAuth token 刷新时卡在"reconnecting"的问题
- 📋 修复 `/workflows` 在 turn 进行中无法立即打开的问题
- 🔋 降低响应流式输出和 spinner 动画期间的 CPU 占用
- ⏱️ Vertex/Foundry 恢复 5 分钟空闲超时，防止流式无响应时无限挂起
- 其余大量可靠性 bug 修复
