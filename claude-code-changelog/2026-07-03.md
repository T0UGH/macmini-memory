# Claude Code Changelog — 2026-07-03

> 今日检查时间：2026-07-03

## 近 2 天新版本（2026-07-02 / 2026-07-01）

---

### v2.1.199 — 2026-07-02

- **堆叠式 slash-skill 调用**：连续调用多个 slash-skill（如 `/skill1 /skill2`）时，现在会预加载所有技能（最多 5 个），切换更流畅
- **SSL 证书错误修复**：SSL 证书相关错误现在有更清晰的引导提示
- **流式响应修复**：中途错误不再导致流式输出被丢弃
- **子 Agent 限流静默失败修复**：子 Agent 遇到速率限制不再静默终止
- **后台 Agent 守护进程修复**：Linux 上后台 Agent 守护进程自杀问题已修复
- **429 错误自动重试**：瞬时服务器 429 错误现支持自动退避重试

---

### v2.1.198 — 2026-07-01

- **Chrome 内置 Claude 正式开放**：Claude in Chrome 现已全面可用（GA）
- **新增 `/dataviz` 技能**：内置图表与仪表盘设计助手
- **Claude Platform on AWS**：Gateway 新增 AWS 上游（`anthropicAws`）作为上游 Provider
- **后台 Agent 自动提交 PR**：后台 Agent 现在会自动 commit、push 并打开 Draft PR
- **子 Agent 默认后台运行**：Subagents 现在默认在后台运行，减少主会话干扰
- **Focus Mode 改进**：子 Agent 的 Focus Mode 体验进一步优化
