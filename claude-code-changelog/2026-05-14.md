# Claude Code Changelog — 2026-05-14

> 今日共发现 2 个新版本（2026-05-12 ~ 2026-05-13）

---

## v2.1.141 — 2026-05-13

### 新增功能
- **Hook terminalSequence**：hooks 可在无控制终端环境下发送桌面通知、窗口标题、响铃
- **HTTPS 插件克隆**：`CLAUDE_CODE_PLUGIN_PREFER_HTTPS` 环境变量，优先使用 HTTPS 而非 SSH 克隆插件
- **ANTHROPIC_WORKSPACE_ID**：工作负载身份联邦，支持指定 workspace 范围
- **claude agents --cwd**：限定会话列表的作用域目录
- **反馈支持历史会话**：`/feedback` 现可包含最近 24 小时或 7 天的会话片段
- **回溯菜单新增 "Summarize up to here"**：压缩早期上下文同时保留最近对话
- **长思考 spinner 增强**：思考超过 10 秒时 spinner 变为琥珀色，提示仍在运行
- **插件菜单优化**：`→`/Tab 切换标签页，`↑` 移至标签栏，标签头和搜索框可点击

### Bug 修复
- 修复后台 side-queries 在 Bedrock/Vertex/Foundry/gateway 上发送不可用 Haiku 模型 ID 的问题
- 修复 Windows 上 `claude daemon status` 和 `/doctor` 在管道文件锁定时报错不明确的问题
- 修复 `/tui` 静默丢弃后台 shells 和 subagents 的问题
- 修复 Windows Alt+V 粘贴截图报错 "no image found" 的问题
- 修复 SDK 在同时安装 glibc 和 musl 的 Linux 上找不到原生二进制文件的问题
- 修复 `claude agents` 在工作目录被删除时触发冗余派发的问题
- 修复 `/model` 在一个 session 中悄悄改变其他并发 session 的自动压缩阈值的问题
- 修复轻量主题（light-ansi）在浅色背景上 diff 上下文行不可见的问题
- 修复 `/feedback` 重定向后输出 JSON 引用值无效的问题
- 修复 Remote Control 工作会话 token 轮换时所有连接报 401 的问题
- 修复 Remote Control 在服务器拒绝过期 token 时陷入循环的问题
- 修复 bed rock `awsCredentialExport` 在有环境凭证时跳过的问题（现已始终运行，修复跨账户访问）
- [VSCode] 修复语音模式下麦克风静默时无反馈的问题
- [VSCode] 修复 WSL 语音模式报错信息建议安装缺少的 `sox libsox-fmt-pulse` 包

## v2.1.140 — 2026-05-12

### 新增功能
- **Agent 类型匹配增强**：subagent_type 支持大小写和分隔符不敏感匹配（如 `"Code Reviewer"` → `code-reviewer`）
- **Agent 颜色面板更新**

### Bug 修复
- 修复 `/goal` 在 `disableAllHooks` 或 `allowManagedHooksOnly` 时静默挂起的问题
- 修复符号链接设置文件导致热重载时触发错误 `ConfigChange` hooks 的回归问题
- 修复 `claude --bg` 在后台服务即将空闲退出时报 "connection dropped mid-request" 的问题
- 修复 Windows 上缺失可执行文件（如 `gh`）导致每次检查都同步重试事件循环卡死的问题
- 修复 `Read` 工具在 `offset` 参数为空白填充或 `+` 前缀字符串时校验失败的问题
- 修复托管 `extraKnownMarketplaces` 自动更新策略未持久化到 `known_marketplaces.json` 的问题
- 修复 `/loop` 为已通过完成通知的后台任务安排冗余唤醒轮询的问题
- 插件现已警告当 `plugin.json` 设置了匹配键时默认组件目录被静默忽略的情况
