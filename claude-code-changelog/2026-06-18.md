# Claude Code Changelog — 2026-06-18

## v2.1.181
**发布日期：** 2026-06-17

- 新增 `/config key=value` 语法，可从 prompt 中直接设置任意配置项
- 新增 `sandbox.allowAppleEvents` opt-in 配置，支持 macOS Apple Events
- 新增 `CLAUDE_CLIENT_PRESENCE_FILE` 环境变量，用于移动端推送通知抑制
- 升级内置 Bun 运行时至 1.4 版本
- 优化长段落流式输出（文字逐行显示）
- 修复自定义 `ANTHROPIC_BASE_URL` 和 Foundry 下 prompt 缓存的问题
- 修复 Write/Edit 工具在网络驱动器上写入 0 字节文件的问题
- 修复启动性能回退（在新环境中每次启动约 120ms）
