## TL;DR for Feishu
1. **Claude Code 的重点已经从“写好 prompt”转向“把仓库组织成适合 agent 思考的形状”**。`CLAUDE.md + skills + hooks + docs` 这套 repo 结构正在变成事实标准。  
2. **Claude Code 新增 Code Review**，而且不是单 agent 过 PR，而是“派一组 agents 并行找 bug”。这说明 Anthropic 正在把多 agent 工作流产品化。  
3. **Claude 生态的最佳实践正在收敛**：先计划、拆子任务、局部上下文、可复用 skill、自动 guardrails，这些都不再是零散技巧，而是开始形成 workflow 模板。  
4. **MCP 方向的主要痛点已经从“有没有工具”转向“工具太多、schema 太重、上下文太贵”**。新方案都在打“按需发现工具”和“减少 prompt 注入”。  
5. **MCP + coding agent 的组合正在从 demo 走向工程化**：不只是接工具，而是开始出现 orchestration layer、可部署 MCP server、结构化工作流。  
6. **OpenAI 的 GPT-5.x / Codex 明显在冲 coding agent 场景**：1M context、computer use、tool-heavy workflow、更快模式，基本都是在打复杂工程任务。  
7. **Claude vs Codex 的竞争点正在变清楚**：Claude 生态更强在 repo workflow / multi-agent / 守护式工程流；Codex 更强在超长上下文、速度和 OpenAI 平台一体化。  
8. **对资深程序员最重要的信号**：未来不是“AI 替你写几个函数”，而是“你是否会把代码库改造成 agent 可以稳定工作的系统”。
