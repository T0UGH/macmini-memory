## TL;DR for Feishu
- Claude Code’s remote-control workflow kept picking up steam on X, with Anthropic’s Boris Cherny resurfacing the strongest demo: start a Claude Code session on your laptop from your phone. The practical implication is that terminal agents are becoming persistent, cross-device workflows rather than desk-bound tools.
- Perplexity pushed hardest on the “agent follows you across devices” angle: Perplexity Computer is now on mobile for iOS with cross-device sync, which makes the personal-computer-agent category feel more real and more competitive.
- Perplexity also added NVIDIA Nemotron 3 Super across Perplexity, Agent API, and Computer, reinforcing the emerging pattern that agent products are becoming multi-model routers instead of single-model shells.
- GitHub showed a solid Copilot SDK pattern: trigger a Remotion-based video-generation workflow directly from WhatsApp. The important part is not the demo itself, but that agent actions are being packaged as portable, pluggable workflows that can start from chat surfaces.
- On the research side, DAIR highlighted a useful reality check: RL fine-tuning can make agents much stronger in familiar environments, but transfer to unseen environments is still weak. Good reminder not to overread benchmark gains as general agent competence.
- Another high-signal research item from DAIR/IBM: self-improving agents with trajectory-derived memory showed meaningful gains, especially on harder tasks. This lines up with the broader shift from “better prompts” to “systems that learn from their own work history.”
- Simon Willison’s new “agentic engineering” talk is worth opening because it reflects where the builder conversation is moving: from chatbot UX toward orchestration, tooling, evaluation, and human-supervised systems engineering.
- A notable macro/opinion thread from @dominic_w argues that inference-centric hardware and agent-generated training data may become the next big infra bottleneck. It’s speculative, but directionally consistent with the broader move from static models to always-running agent systems.
- X was noisy as usual: many high-engagement posts in this window were affiliate-style Claude/OpenClaw/Codex hype or DM-gated tutorials. This report intentionally filtered toward direct-source product posts, research summaries, and durable workflow signals.
