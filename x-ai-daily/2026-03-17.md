- @steipete 同步确认 OpenShell + NemoClaw 是和 NVIDIA 一起做出来的，重点是“secure agents you can trust”。说明 OpenClaw 生态现在不只是个人玩具，已经开始往可信执行环境和企业交付靠。

- GitNexus 这类 repo knowledge graph + MCP 的工具开始获得传播，目标很明确：让 Claude Code / Cursor 这类 coding assistant 真正理解整仓库，而不是只盯当前文件。对大仓库工作流很有现实价值。
- Minko Gechev 发布 skillgrade，用两条命令给 agent skills 跑 eval，而且默认在安全沙箱里执行。信号点是：agent 生态开始把“技能评测”单独产品化，可靠性正在从口号变成流程。

## 6. 总结
- 今天最大的趋势：coding agent 正在从“单 agent 回答问题”快速走向“多 agent 编排 + 常驻运行 + 安全受控部署”。Codex 的 subagents 和 NemoClaw 的企业化包装，都是这个方向的直接证据。
- 哪些值得行动：
  - 持续跟踪 Claude Code / Codex / OpenClaw 在 subagent、远程触发、常驻运行上的能力收敛。
  - 重点盯 repo understanding、MCP、skills/evals 这三块配套层，它们决定 agent 能不能从 demo 走向稳定生产力。
  - 安全部分要特别关注发布链路、证书、安装包和运行时权限，不要只盯模型本身。
- 哪些基本是噪音：
  - 大量“用 Claude / OpenClaw 轻松赚几千几万美金”的帖子依旧很多，绝大多数是引流 DM、卖课、卖模板。
  - 本窗口里和 Claude 相关的高互动内容有不少，但真实可验证的新产品/新 API 信号偏少，需主动去噪。
