# X AI Daily

Daily X/Twitter AI intelligence reports.

## Defaults
- Timezone: Asia/Shanghai
- Delivery time: 08:30 daily
- Lookback window: 48 hours
- Surface delivery: Feishu summary only
- Archive: full markdown in this directory
- Focus: all AI news, with emphasis on Claude ecosystem, agents, and coding
- Method: watchlist accounts + keyword tracking
- Git policy: auto commit + push

## Scoring dimensions
Each item should include:
- Importance
- Technical Depth
- Practical Value
- Relevance to user
- Programmer Survival Index

## File naming
- Daily report: `YYYY-MM-DD.md`
- Optional config/reference files live beside this README.


## Author + link rules
- Full markdown items must include the original author handle when available.
- Feishu summary should stay concise and include the GitHub report link at the end for full reading.
- If the source tool cannot resolve an author handle, prefer a best-effort lookup before publishing.
