- @simonw 放出 3 小时 workshop handout，主题是用 Codex CLI、Claude Code 做数据探索、可视化和分析。信号点是 coding agent 已明显从“写代码”扩展到更广义的知识工作流。

- @GoogleCloudTech 用一句很到位的话解释 MCP 与 Skill：MCP 像铲子，Skill 像教你怎么挖的书。这个分层判断对理解 agent 体系很有帮助，也解释了为什么“光接协议”还不够。

## 6. 总结
- 今天最大的趋势：agent 生态继续从“会聊天的模型”走向“可拆分、可编排、可自动化、可部署的工程系统”。
- 哪些值得行动：
  - 持续跟踪 Claude Code / Codex / OpenClaw 在 subagent、隔离执行、headless 自动化上的能力收敛。
  - 关注本地模型生态如何继续补齐搜索、抓取、CI、插件等执行层能力。
  - 把“协议层（MCP）”和“方法层（Skills / workflow）”分开看，避免只盯接口不盯工作法。
- 哪些基本是噪音：
  - 大量“某个 agent 又赚了多少钱”的营销型帖子依然很多，信息增量低。
  - 单条 viral demo 若缺少流程、环境、成本、失败面描述，参考价值有限。
