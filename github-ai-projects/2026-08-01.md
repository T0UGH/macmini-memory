### 1. huggingface/speech-to-speech
- **今日新增 stars：** 1,275 ⭐（最热项目）
- **总 stars：** 10,071
- **语言：** Python

**功能特点：**
- 低延迟、模块化语音 Agent 管道，串联四个组件：VAD（Silero VAD）→ STT（Parakeet TDT）→ LLM（流式响应+工具调用）→ TTS（Qwen3-TTS）
- 全链路可替换，支持本地模型或云端 Provider
- **OpenAI Realtime API 兼容**，直接对标 OpenAI Realtime WebSocket 接口
- 提供 `--local_mac_optimal_settings` 一键本地优化配置
- 支持 faster-whisper、kokoro、chattts 等多种 STT/TTS 后端

**使用方式：**
```bash
pip install speech-to-speech
export OPENAI_API_KEY=...
speech-to-speech
# 或本地 Mac 优化
speech-to-speech --local_mac_optimal_settings
```
Docker：`docker compose up`

### 2. bytedance/deer-flow
- **今日新增 stars：** 204 ⭐
- **总 stars：** 78,598
- **语言：** Python

**功能特点：**
- 字节跳动开源的 SuperAgent 平台，v2.0 全新重构
- 子 Agent 编排 + 沙箱执行 + 长期记忆 + 可扩展技能系统
- 支持 OpenAI / Claude / DeepSeek / Kimi / Codex CLI / Claude Code OAuth
- 内置 MCP Server 支持、LangeSmith/Langfuse 追踪
- 提供命令行 TUI（Terminal Workbench）

**使用方式：**
```bash
git clone https://github.com/bytedance/deer-flow.git && cd deer-flow
make setup        # 交互式初始化，生成 config.yaml
make doctor       # 验证配置
make docker-start # Docker 启动
# 访问 http://localhost:2026
```

### 3. TencentCloud/TencentDB-Agent-Memory
- **今日新增 stars：** 250 ⭐
- **总 stars：** 10,084
- **语言：** TypeScript / Python

**功能特点：**
- 团队级 AI Agent 记忆中枢，将对话、文档、代码转化为四类可复用记忆资产：Chat Memory / Skill / LLM-Wiki / CodeGraph
- 分层记忆架构（L0 原始对话 → L1 原子 → L2 场景 → L3 Persona），测试显示开启后 PersonaMem 提升 59%
- 技能库支持版本管理、触发器和校验规则
- 支持私有/团队/ACL 访问控制，按 Agent Loadout 绑定不同记忆

**使用方式：**
```bash
git clone https://github.com/Tencent/TencentDB-Agent-Memory.git
cd TencentDB-Agent-Memory/deploy/global-images
cp .env.example .env && vim .env  # 配置 LLM 参数
./start-all.sh
# 访问 http://localhost:8125
```
