## 1. Kronos — 金融市场基础大模型 ⭐ 319 stars/day

首个面向金融 K 线（K-line）的开源基础模型，已被 AAAI 2026 录用。

**功能特点：**
- 两阶段框架：专用分词器将 OHLCV 数据量化为层级离散 token，再经自回归 Transformer 处理
- 提供 Mini（4.1M）→ Large（499.2M）四种规模，全部托管在 HuggingFace
- 内置 `KronosPredictor` 推理类，支持批量预测；提供 Qlib 微调脚本

**快速使用：**
```python
from model import Kronos, KronosTokenizer, KronosPredictor
tokenizer = KronosTokenizer.from_pretrained("NeoQuasar/Kronos-Tokenizer-base")
model = Kronos.from_pretrained("NeoQuasar/Kronos-small")
predictor = KronosPredictor(model, tokenizer, max_context=512)
```

> GitHub: `shiyu-coder/Kronos` | MIT License

## 2. ego-lite — AI Agent 专用浏览器 ⭐ 986 stars/day

为 AI Agent 打造的浏览器，人和 Agent 共用同一窗口但工作区完全隔离。

**功能特点：**
- Agent 在独立 "Space" 中运行任务，永久不干扰你的标签页
- 继承 Chrome 登录态 / Cookie / 扩展，体验无缝
- 代码驱动方式减少 token 消耗，复杂任务提速最高 2.5×
- 支持 Claude Code、Codex、Cursor 及自定义 Agent；数据本地存储

**安装使用（macOS）：**
```bash
# 下载 dmg：https://github.com/citrolabs/ego-lite/releases
npx skills add citrolabs/ego-lite
/ego-browser follow @ego_agent on x.com
```

> GitHub: `citrolabs/ego-lite` | MIT License

## 3. turbovec — Rust 向量索引库 ⭐ 89 stars/day

基于 TurboQuant 的数据遗忘型量化器，16 倍内存压缩，比 FAISS 更快。

**功能特点：**
- 1000 万条 float32 向量原本占 31 GB，用 turbovec 仅需 4 GB（16× 压缩）
- 在线建索引，无需单独训练阶段；支持 ID 白名单过滤搜索
- SIMD 优化（ARM NEON / x86 AVX-512BW）
- 集成 LangChain、LlamaIndex、Haystack、Agno；完全本地运行

**安装使用：**
```bash
pip install turbovec        # Python
cargo add turbovec          # Rust
```

> GitHub: `RyanCodrai/turbovec` | MIT License

## 4. Buzz — 人类与 AI Agent 协作平台 ⭐ 2,506 stars/day

Block 公司开源的类 Slack 协作工具，所有消息和工作流均基于 Nostr Relay 签名事件。

**功能特点：**
- 频道、线程、私信、白板、媒体、搜索、审计日志
- `buzz-cli` 专为 Agent 设计（JSON in / JSON out）
- YAML 工作流，支持消息/反应/定时/webhook 触发
- Git 托管、NIP-34 patch 事件支持
- 桌面端：Tauri + React；移动端 Flutter 开发中

**快速启动：**
```bash
git clone https://github.com/block/buzz.git && cd buzz
just setup && just build   # 首次构建
just dev                   # 日常开发
```

> GitHub: `block/buzz` | Apache 2.0
