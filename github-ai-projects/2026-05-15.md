### 4. supertone-inc / supertonic
**语言：** Swift | **今日新增：** ~712 ★ | **总星标：** 5,793

**功能特点：**
- 极速本地 TTS 引擎，基于 ONNX Runtime，完全离线运行，不调用任何云 API
- 支持 **31 种语言**（v3 最新版），语音自然度高
- 跨平台：Python / Go / Java / C# / Swift 多语言 SDK
- 提供 [Voice Builder](https://supertonic.supertone.ai/voice_builder)：可将个人声音定制为可部署的端侧 TTS
- 适合隐私敏感场景（移动端、嵌入式）或需要低延迟的应用

**使用方式：**
```bash
pip install supertonic

python
from supertonic import TTS
tts = TTS(auto_download=True)
wav, duration = tts.synthesize("Hello world", voice_style=tts.get_voice_style("M1"), lang="en")
tts.save_audio(wav, "output.wav")
```
