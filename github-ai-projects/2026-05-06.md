### 1. [aattaran/deepclaude](https://github.com/aattaran/deepclaude)
**⭐ 1430 stars | JavaScript | 2026-05-03 创建**

用 DeepSeek V4 Pro（或 OpenRouter 等任意兼容后端）替代 Claude Code 的后端，保持相同的 UX，操作成本降低 **17 倍**。支持 Claude Code 的自主 agent 循环，直接对接更便宜的大模型 API。

**使用方式：**
```bash
# 安装
npm install -g deepclaude
# 配置 API Key（DeepSeek 或 OpenRouter）
export DEEPSEEK_API_KEY=sk-xxx
# 运行
deepclaude
```
