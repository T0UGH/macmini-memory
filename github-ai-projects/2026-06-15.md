### 1. NVIDIA/SkillSpector ⭐ 6053（今日 Trending 首页）

**功能：** AI Agent Skills 安全扫描器。自动检测 Agent Skills（Claude Code、Codex CLI、Gemini CLI 等使用的技能包）中的安全漏洞、恶意模式和风险。研究数据：**26.1% 的 skills 存在漏洞，5.2% 可能有恶意意图**。

**核心能力：**
- 支持 Git 仓库、URL、zip、本地目录、单个文件多种输入格式
- 覆盖 **64 种漏洞模式**，分 16 大类：提示词注入、数据泄露、权限提升、供应链攻击、MCP 工具投毒等
- 两阶段分析：快速静态分析 + 可选 LLM 语义评估
- 实时查询 OSV.dev CVE 数据库，支持离线回退
- 输出格式：终端 / JSON / Markdown / SARIF，带 0-100 风险评分

**使用方式：**
```bash
# Docker（无需 Python）
docker run --rm -v "$PWD:/scan" skillspector scan ./my-skill/ --no-llm

# 本地安装
git clone https://github.com/NVIDIA/SkillSpector.git
cd SkillSpector
make install
python -m skillspector scan ./my-skill/
```

### 2. renee-jia/scholar-loop ⭐ 59（今日新 push）

**功能：** 自主 AI 科学家——运行完整科研循环：读论文 → 找 gap → 做真实实验 → 反思 → 撰写 & 同行评审。8 个 Agent 协作，deterministic harness 防止 reward-hacking。

**核心架构（8 Agent）：**
| Agent | 职责 |
|---|---|
| Director | 读账本 + 文献趋势 → 设定下一步方向 |
| Lit Scout | 抓取真实 arXiv 论文 → 结构化引用发现 |
| Reasoner | 约束 + 文献 + 历史教训 → 生成实验假设 |
| Debate Panel | 三个角色投票：该方向值不值得 GPU？ |
| Funnel | 快速筛选 → 验证 → 完整实验 |
| Runner | 运行真实 PyTorch 实验，由冻结指标评分 |
| Reflector | 将结果转为记忆存入 decaying skill library |
| Advisor | 决策：PROCEED / REFINE / PIVOT |

**使用方式：**
```bash
git clone https://github.com/renee-jia/scholar-loop.git
cd scholar-loop
pip install -r requirements.txt
python run.py  # 启动科研循环（默认跑 sklearn digits MLP，CPU 快速）
```
