## 今日最值得关注项目

### 1. system-prompts-and-models-of-ai-tools ⭐ 140.6k
- **链接**：https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools
- **功能**：收录 30+ AI 编程助手（Cursor、Claude Code、Devin、Windsurf 等）的 system prompt 和模型信息，规模最大的 AI 透明度资源库
- **使用**：`git clone` 后按项目名查阅各 AI 工具的内部 prompt 设计

### 2. agent-skills ⭐ 60.9k
- **链接**：https://github.com/addyosmani/agent-skills
- **功能**：AI 编程 Agent 的生产级工程技能库，24 个结构化技能（Define/Plan/Build/Verify/Review/Ship），跨 Claude Code、Cursor、Gemini CLI 等多工具通用
- **使用**：`npm install -g @agent-skills/cli` 后按需激活技能

### 3. last30days-skill ⭐ 43.3k
- **链接**：https://github.com/mvanhorn/last30days-skill
- **功能**：AI Agent 研究技能，并行搜索 Reddit/X/YouTube/HN/Polymarket 等 15+ 平台，按真实互动信号排序，可导出 HTML 简报
- **使用**：安装后在 Agent 中调用 `/last30days <主题>` 即可获得基于群众智慧的研究报告

### 4. VoxCPM ⭐ 30k
- **链接**：https://github.com/OpenBMB/VoxCPM
- **功能**：无 tokenizer 的端到端 TTS 系统，支持 30 种语言（含 9 种中文方言），RTF 低至 0.13，Apache-2.0 商业可用
- **使用**：`pip install voxcpm`，`vox.generate("你好世界", output="audio.wav")`

### 5. Agent-Reach ⭐ 31.7k
- **链接**：https://github.com/Panniantong/Agent-Reach
- **功能**：让 AI 编程 Agent（Claude Code、Cursor 等）能够搜索和阅读整个互联网，支持 Twitter/Reddit/YouTube/Bilibili 等 12+ 平台
- **使用**：安装后在 Agent 配置中引入 Agent-Reach 后端，完全免费，自动处理反爬机制

### 6. open-notebook ⭐ 31k
- **链接**：https://github.com/lfnovo/open-notebook
- **功能**：开源隐私优先的 NotebookLM 替代品，支持 18+ AI Provider（OpenAI/Anthropic/Ollama），可生成播客、全文检索，MIT 许可
- **使用**：`docker run -p 8000:8000 lfnovo/open-notebook`，浏览器打开使用

### 7. headroom ⭐ 29.7k
- **链接**：https://github.com/chopratejas/headroom
- **功能**：AI 编程 Agent 的上下文压缩层，Token 减少 60-95% 且可逆，支持工具输出、日志、对话历史等所有上下文类型
- **使用**：以代理模式部署，`headroom serve --port 8080`，无需修改代码

### 8. zvec ⭐ 10.3k
- **链接**：https://github.com/alibaba/zvec
- **功能**：阿里巴巴开源的进程内向量数据库，支持数十亿向量毫秒级检索，密疏向量混合检索 + 全文搜索，Python/Go/Node.js SDK 全支持
- **使用**：`pip install zvec`，`zvec.index(dim=768).add(vectors).search(query, top_k=10)`

### 9. LMCache ⭐ 9.2k
- **链接**：https://github.com/LMCache/LMCache
- **功能**：LLM 推理 KV Cache 持久化管理，将临时缓存转化为可复用知识，支持 GPU→CPU→Redis/S3 卸载，降低 TTFT
- **使用**：`pip install lmcache`，推理代码中集成 LMCache 后端即可

### 10. SkillSpector ⭐ 6.9k
- **链接**：https://github.com/NVIDIA/SkillSpector
- **功能**：NVIDIA 开源的 AI Agent 技能安全扫描器，检测 64 种漏洞模式（Prompt 注入/数据泄露/权限提升等），支持 Claude Code/CoDEX CLI/Gemini CLI
- **使用**：`pip install skillspector`，`skillspector scan ./my-skills --output sarif`
