## 🏆 今日重点推荐

### 1. jd-opensource/JoyAI-Echo
**⭐ 228 | Python | 京东开源**

**功能特点：** 京东开源的长视频生成框架，实现**分钟级多镜头音视频联合生成**。核心技术包括：跨模态音频-视觉记忆库（保持5分钟视频中人物外观和声音一致性）、DMD蒸馏推理（比原管线快7.5倍）、联合音视频生成管道、对话式实时编辑Agent。人类评估中，在视觉美学（63.6%）、音频质量（81.7%）、Prompt遵循度（80.6%）上均大幅领先竞品。

**使用方式：**
```bash
pip install joyai-echo
python scripts/generate.py --config configs/echo_long.yaml
```
HuggingFace权重已发布：[huggingface.co/jdopensource/JoyAI-Echo](https://huggingface.co/jdopensource/JoyAI-Echo)

### 2. Fullive-AI/Anima
**⭐ 167 | Python | Agent OS**

**功能特点：** 开源**智能硬件 Agent 操作系统**，"让每一件硬件都有灵魂"。Anima 将家中的灯光、空调、加湿器、空气净化器、音箱等设备连接到一个可运行的智能中心，具备感知、决策、学习和扩展能力。核心模块：设备自动发现（零配置）、LLM Brain（支持任意 OpenAI 兼容 API）、Memory 系统（学习用户偏好）、Skill 系统（为每个设备类型封装领域知识）、Dashboard + REST API + CLI。目前支持米家/MIoT设备。

**使用方式：**
```bash
git clone https://github.com/Fullive-AI/Anima
cd Anima && pip install -e .
anima init   # 扫码登录米家，自动发现设备
anima run    # 启动 Agent Runtime
```

### 3. Soul-AILab/SoulX-Transcriber
**⭐ 124 | Python | 语音识别**

**功能特点：** 端到端**多说话人识别转录框架**，联合建模"谁在说话 + 何时说话 + 说了什么"，无需级联管道。在 AISHELL-4 数据集上 DER=2.89%、WER=14.16%，在 AliMeeting 上 DER=5.39%、WER=13.07%，均达到 SOTA 水平。支持重叠对话和快语速转换的流式处理。

**使用方式：**
```bash
pip install soulx-transcriber
python -m soulx_transcriber.run --audio_path your_meeting.wav
```

### 4. PanisHandsome/ai-rules-sync
**⭐ 84 | JavaScript | 开发工具**

**功能特点：** 统一管理多款 AI 编码助手的规则配置（AGENTS.md / CLAUDE.md / .cursorrules / Copilot / Windsurf / Cline / Aider / Gemini），实现一处编写、多平台同步。零依赖，支持从零生成 AGENTS.md，适合团队标准化 AI 编码规范。

**使用方式：**
```bash
npx ai-rules-sync convert  # 自动同步到所有平台
npx ai-rules-sync scaffold  # 从模板生成 AGENTS.md
```

### 6. anvia-hq/lexa
**⭐ 41 | Rust | 代码智能**

**功能特点：** 面向 AI Agent 的**快速本地代码智能引擎**，将代码库转换为可移植、可查询的图结构，让所有 AI 工具基于同一稳定视图工作。支持代码语义搜索、依赖关系图分析，提升 Agent 在大型代码库中的推理效率。

**使用方式：**
```bash
lexa index ./your-project
lexa query "如何实现缓存？" --agent-mode
```
