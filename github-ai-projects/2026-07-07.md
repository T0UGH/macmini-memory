**功能特点：**
Hermes Agent 的原生 iPhone 应用。Hermes 是一个自托管 LLM Agent 框架，Hermex 提供优雅的 iOS 界面，让用户随时随地与本地部署的 AI Agent 交互。纯 SwiftUI 开发，支持 self-hosted 模型，保护隐私。

