### 1. [apple/container](https://github.com/apple/container) — macOS 上的轻量级 Linux 容器
- **语言**：Swift
- **⭐ 105 stars / 1 fork**（今日最高增长项目）
- **功能**：在 Mac 上用轻量级虚拟机创建和运行 Linux 容器，专为 Apple Silicon 优化。使用 Swift 编写，资源占用极低。
- **使用方式**：
  ```bash
  # 安装（需 macOS + Apple Silicon）

  cd container && swift build -c release
  # 创建容器
  container run --image ubuntu:latest
  ```

### 2. [chopratejas/headroom](https://github.com/chopratejas/headroom) — LLM Token 压缩器
- **语言**：Python
- **⭐ 38 stars / 2 forks** | score: 354（Python 类目第一）
- **功能**：在工具输出、日志、文件和 RAG 分块送达 LLM 之前进行压缩，节省 60-95% 的 Token，同时保证答案质量。支持 Library、Proxy 和 MCP Server 三种模式。
- **使用方式**：
  ```bash
  pip install headroom
  # 作为 MCP Server 使用
  headroom mcp-server
  # 或在代码中调用
  from headroom import compress
  compressed = compress(your_context)
  ```

### 4. [rtk-ai/rtk](https://github.com/rtk-ai/rtk) — 开发命令 Token 节省 60-90%
- **语言**：Rust
- **⭐ 16 stars** | 单二进制文件，零依赖
- **功能**：CLI 代理，拦截常见开发命令（git diff、npm ls 等）的输出，在发送给 LLM 前进行压缩，适用于 Claude Code、OpenClaw 等编程 Agent。实测节省 60-90% Token。
- **使用方式**：
  ```bash
  # 安装
  curl -fsSL https://rtk-ai/rtk/install.sh | sh
  # 配置 Claude Code 使用 rtk 作为 proxy
  rtk proxy --port 8080
  ```
