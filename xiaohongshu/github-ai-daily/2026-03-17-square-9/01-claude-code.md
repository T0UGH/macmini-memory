## anthropics/claude-code
**claude-code v2.1.77**

发布时间：2026-03-17 08:28

- 这版不是小修小补，而是把 Claude Code 在长会话、tmux、权限与恢复链路上的几个高频痛点一起收拾了一遍。
- Claude Opus 4.6 默认最大输出上限提到 64k，Opus 4.6 / Sonnet 4.6 的上限提到 128k，长任务和长代码生成空间更大了。
- 新增 `allowRead` 沙箱文件系统设置：可以在 `denyRead` 的大区块里对局部目录重新开白名单，权限控制更细。
- `/copy` 现在支持 `/copy N`，可以直接复制倒数第 N 条 assistant 回复，回收历史输出更方便。
- 修复 `--resume` 在近期历史加载上的截断问题；大 session 的恢复速度也继续优化，官方给出的量级是最高约 45% 更快、峰值内存下降约 100-150MB。

**一句话**
这版不是小修小补，而是把 Claude Code 在长会话、tmux、权限与恢复链路上的几个高频痛点一起收拾了一遍。
