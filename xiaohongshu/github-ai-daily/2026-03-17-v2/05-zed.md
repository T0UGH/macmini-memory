# zed-industries/zed
## 今天最值得看的点：`spawn_agent`

- 最新版本：`v0.227.1`
- 发布时间：2026-03-11 23:41（北京时间）
- 关键更新：新增 `spawn_agent`

### 这意味着什么？
它允许在 Zed 里并行调度子代理，
也就是把“多 agent 工作流”直接推进到编辑器主流程里。

### 同时还有这些补强
- 支持 GPT-5.3-Codex 自带 Key 模式
- 新增 Vercel AI Gateway provider
- agent 对话中可从 diff 跳回文件
- 草稿提示词、思考模式等状态持久化更完整

**Zed 不是在试验 agent，而是在认真把 agent 变成编辑器主能力。**
