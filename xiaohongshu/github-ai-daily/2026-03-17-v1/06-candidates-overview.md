# 5. 今天的新仓候选，透露了三个明显方向

今天候选仓库不少，但我觉得真正值得记住的不是名字，
而是背后的方向：

## 方向一：协议 / 接入层
像 `routa`、`fast-agent`、`obsidian-agent-client` 这类项目，
都在试图解决 agent 怎么和不同工具、不同协议接起来。

## 方向二：上下文 / 记忆层
像 `gitclaw`、`serena` 这类项目，
都在围绕 repo memory、semantic retrieval、上下文理解做事。

## 方向三：调度 / 工作流层
像 `arbor`、`pi-subagents` 这类项目，
都在想办法把 subagents、worktree、多任务协作落到现实工作流里。
