**它是做什么的**
NornicDB is a high-performance graph + vector database built for AI agents and knowledge systems. Compatible w/Neo4j (Bolt/Cypher) and qdrant's (gRPC) drivers so you can switch with zero code changes, while adding intelligent features like local LLM inference, embeddings, HNSW+rerank search, GPU acceleration, Auto-TLP, Memory Decay, and MCP server。
