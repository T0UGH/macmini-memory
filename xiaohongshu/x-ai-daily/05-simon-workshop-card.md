## Simon 放出 workshop handout：Codex CLI 和 Claude Code 已经进入真实数据工作流

这条内容不是新产品发布，而是一份更有落地味道的材料。  
Simon Willison 把他在 NICAR 数据新闻会议上的 workshop handout 放了出来，主题很直接：**如何用 Codex CLI、Claude Code 等 coding agents 做数据探索、可视化和分析**。

这类材料最值得看的地方，不是“他又用了哪些工具”，而是它表明 coding agents 的使用场景已经明显往外扩：

- 不只是写代码
- 也不只是改 bug
- 开始进入数据探索
- 进入可视化
- 进入分析和调查型工作

这意味着 coding agent 正在从典型的软件开发场景，延伸到更广的知识工作里。  
而且 workshop handout 这种形式本身也说明，相关方法已经不只是个人经验，而是开始可以教学、复用、复制。

原文真正释放的信号是：  
builder 们已经开始把 coding agents 当成一套可训练、可迁移的方法，而不是临时灵感工具。

### 为什么值得看
因为当一项能力开始进入 workshop 和 handout，它往往说明“能不能用”这个问题已经过去，接下来拼的是“怎么用得更稳、更广”。
