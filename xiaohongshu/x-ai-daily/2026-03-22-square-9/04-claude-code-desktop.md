## Claude Code Desktop 可直接点选 DOM：拿到结构、样式、截图，React 还给源码定位

> Claude gets the tag, classes, key styles, surrounding HTML, and a cropped screenshot. React apps also get the source file, component name and props

### 我的判断
这不是花哨 UI，而是把前端 agent 最痛的一步——“你到底改哪块”——从模糊描述变成了结构化定位。尤其 React 还能回收到具体源文件和 props，这会显著减少 agent 在前端改动里的猜测成本。

### 为什么值得看
前端修改一直容易因为上下文不精确而返工。这种“视觉点选 + 结构上下文 + 组件定位”的组合，是真正能提升桌面 coding agent 可用性的工作流补丁。
