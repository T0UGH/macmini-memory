## skillgrade 发布：agent skills 的 eval 开始被工具化、沙箱化

Minko Gechev 发布 skillgrade，用 `skillgrade init` 和 `skillgrade` 两条命令建立并运行 agent skills 的评测；默认在安全的 sandboxed Docker container 中执行。

### 为什么值得看
agent 领域一个长期缺口是“大家都在做技能，但很少有人系统验证”。skillgrade 这类工具意味着技能评测正在被产品化，后续谁的 agent 体系更可靠，未必取决于会不会讲故事，而是取决于 eval 做得够不够硬。
