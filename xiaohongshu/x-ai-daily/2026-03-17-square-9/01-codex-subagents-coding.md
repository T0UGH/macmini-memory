## Codex 正式支持 subagents，coding agent 进入“并行分工”阶段

OpenAI Developers 宣布 Codex 已支持 subagents，可用于保持主上下文干净、并行处理任务不同部分，以及在执行过程中分别 steer 各个 agent。

### 为什么值得看
这条更新的价值不在“又多了个功能”，而在它把 coding agent 的工作单位从单线程对话，推进到可编排的多 agent 协作。对复杂代码修改、调研+实现拆分、长任务降噪都非常关键，也会反向抬高用户对 Claude Code / OpenClaw 等产品的能力期待。
