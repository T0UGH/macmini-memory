## Codex 正式支持 subagents，coding agent 进入并行编排时代

OpenAI Developers 宣布 Codex 已支持 subagents，可用于保持主上下文干净、并行处理任务不同部分，并在执行过程中分别 steer 各个 agent。

### 为什么值得看
这不是普通的小更新，而是工作模型的升级。过去很多 coding agent 的瓶颈都来自上下文污染、任务拆分困难、长任务失控。subagents 让复杂任务更接近“组织协作”而不是“单线程聊天”。
