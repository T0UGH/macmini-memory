## Ollama 0.18.1 为 OpenClaw 增加 web search / fetch，并支持 headless 自动化

Ollama 0.18.1 新增 OpenClaw 的 web search / web fetch 插件，并让 `ollama launch` 支持非交互 headless 模式，明确面向 Docker、CI/CD、脚本自动化与评测流水线。

### 为什么值得看
这类更新的价值在于“补齐能跑生产流程的工具细节”。本地模型要想真正进入 coding/agent 工作流，搜索、抓取、自动化启动这些能力比单纯模型分数更重要。
