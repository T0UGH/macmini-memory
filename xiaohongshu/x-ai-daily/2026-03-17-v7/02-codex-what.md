# 1. Codex 支持 subagents，到底变了什么？

这件事的重点不是“多了个功能按钮”，而是 coding agent 的工作方式变了。

以前更常见的是：
- 一个 agent 同时查资料、改代码、跑测试、写说明
- 任务一长，上下文就越来越脏
- 人要反复把背景重新讲一遍

现在支持 subagents 后，意味着可以变成：
- **主 agent 负责总控**
- 一个 subagent 专门做调研
- 一个 subagent 处理具体模块改动
- 一个 subagent 跑测试和验证

本质上，这不是“会不会写代码”的问题，
而是 **长任务能不能拆开并行做** 的问题。
