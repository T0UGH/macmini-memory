# 还有一个信号：skillgrade 开始补“评测”

skillgrade 这类工具做的事情也很关键：
给 agent skills 跑 eval，而且默认放在安全沙箱里执行。

这说明 agent 生态开始认真补一块以前常被忽略的东西：
**可靠性验证。**

以前很多人做 skill、workflow、prompt，
更像是在堆经验和技巧。
但接下来，真正有价值的问题会变成：
- 这个 skill 能不能稳定复现
- 换个环境会不会失效
- 出问题能不能系统排查

谁能把 eval 补起来，谁的 agent 体系才更靠谱。
这也是为什么我会把它当成一个基础设施信号，而不是小工具新闻。
