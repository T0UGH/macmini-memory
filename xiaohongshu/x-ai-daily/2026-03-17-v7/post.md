# AI Agent正在变天

这两天最值得看的，不是哪家又发了一个更强模型，而是 coding agent 生态开始同时补三件事：多 agent 编排、常驻运行、可信部署。

我会重点记 5 个信号：
1. Codex 支持 subagents，意味着 coding agent 开始从单线程对话走向多 agent 分工。
2. NVIDIA 推 NemoClaw，说明 agent 正在被往 always-on、secure、可部署的基础设施方向包装。
3. OpenClaw 生态开始强调 secure agents you can trust，说明行业焦点从“能不能跑”转向“能不能托付”。
4. GitNexus、skillgrade 这类工具升温，说明 repo understanding 和 skill eval 正在变成配套基础设施。
5. 安全上真正危险的，往往不是模型，而是安装包、证书、发布链路和权限边界这些工程问题。
