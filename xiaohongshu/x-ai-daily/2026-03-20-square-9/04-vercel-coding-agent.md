## Vercel 把 coding-agent skills 做成插件分发层：一次 `npx plugins add`，整包能力注入 Claude Code / Cursor

> Running npx plugins add gets you every Skill and keeps them updated.

### 我的判断
这一条很像 coding-agent 世界里的“包管理层”信号。真正大规模用 skill 时，瓶颈很快就不再是会不会写 skill，而是 **怎么发现、安装、更新、组合、避免过期**。Vercel 明显在把这件事产品化。

### 为什么值得看
贵平重视规则、配置、验证、可重复流程。插件化分发正好比“散落一地的 skill 文件”更接近可维护体系。如果这条跑通，skills 会从提示工程附属物，变成 agent 平台的能力供应链。
