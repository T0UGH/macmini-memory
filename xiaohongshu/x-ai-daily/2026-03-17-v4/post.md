# 这两天 AI 圈最值得看的，不是新模型，而是 coding agent 开始补基础设施

过去 48 小时我最在意的，不是哪家又发了一个更强模型，而是 coding agent 生态开始在三个方向上明显收敛：多 agent 编排、常驻运行、可信部署。

最典型的几个信号：
1. Codex 正式支持 subagents，这意味着 coding agent 正在从“单线程对话”走向“主 agent + subagents”的协作模式。
2. NVIDIA 推 NemoClaw，这件事的重点不是 demo，而是 agent 被往 always-on、secure、可部署的基础设施方向包装。
3. OpenClaw 生态开始反复强调 secure agents you can trust，说明行业焦点已经从“能不能跑”转向“能不能托付”。
4. GitNexus、skillgrade 这类工具升温，也说明 repo understanding、skill eval、MCP/context infrastructure 正在变成配套基础设施。
5. 安全侧也再次提醒：agent 产品真正容易出事的，往往不是模型，而是安装包、证书、发布链路和权限边界这些工程问题。

如果只记一句话：
**2026 年的 agent 竞争，已经不只是“谁更聪明”，而是“谁更会编排、谁更能长期运行、谁更值得信任”。**
