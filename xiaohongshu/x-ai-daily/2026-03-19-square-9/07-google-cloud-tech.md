## Google Cloud Tech 用一句话把 MCP 与 Skill 的分层讲明白：工具接入不等于会做事

> An MCP is the shovel, but the Skill is the book that teaches you how to dig.

### 我的判断
这条虽然短，但认知价值挺高。最近很多 agent 讨论里，大家把协议、工具、skill、prompt、workflow 混成一锅。这个类比提醒得很准：**可调用 ≠ 可完成任务**，真正的可用性来自“工具 + 方法 +约束”的组合。

### 为什么值得看
贵平长期在看 coding agent / OpenClaw / skills，这正是方法论层的关键分界线。理解这个分层，能更快判断一个 agent 产品到底是“会接工具”还是“真能交付结果”。
