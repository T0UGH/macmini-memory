## Boris 转推远程触发：Claude Code 开始更像随时可唤起的工作进程

Boris Cherny 转推的这段演示，表面上看只是一个很酷的小功能：

- Claude Code 不再只能守在本机终端前手动启动
- session 可以被远程叫醒

- 使用方式从“坐到电脑前再用”，变成“想到就能触发”

原文里这条演示真正让人注意的，就是 Claude Code 正在一点点从“终端里的强工具”，变成“可以嵌进日常生活节奏的工作进程”。
