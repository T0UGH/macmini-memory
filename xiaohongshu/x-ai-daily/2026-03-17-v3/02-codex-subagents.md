# 信号 1：Codex 正式支持 subagents

这件事为什么重要？
因为它不是“多了个功能按钮”，而是改变了 coding agent 的工作单位。

以前更常见的是：
- 一个 agent 同时做调研、改代码、跑测试、写说明
- 上下文越做越脏
- 任务一长就容易失控

现在支持 subagents 之后，意味着可以变成：
- 主 agent 负责总控
- 一个 subagent 去查资料
- 一个 subagent 去改某个模块
- 一个 subagent 去跑验证

## 这对普通开发者意味着什么？
它会直接影响三件事：
1. 长任务的稳定性
2. 大项目里的上下文管理
3. “调研 + 实现 + 验证”能不能真正拆开并行

所以我会把它看成：
**coding agent 从单线程对话，进入多 agent 编排阶段。**
