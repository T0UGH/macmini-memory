## Vercel 把 skills 往分发层推进：一条 `npx plugins add`，给 Claude Code / Cursor 注入整包生产部署能力

> Running npx plugins add gets you every Skill and keeps them updated.

### 我的判断
这条很像 coding-agent 生态里的“包管理层”开始成形。真正把 skills 用深之后，瓶颈不会停留在“有没有 skill”，而会迅速变成 **怎么分发、怎么更新、怎么组合、怎么避免能力过期**。Vercel 明显在把这层产品化。

### 为什么值得看
贵平重视规则、配置、验证和可重复流程。插件化分发比散落的 skill 文件更接近真正能维护、能升级、能团队化复用的能力供应链。
