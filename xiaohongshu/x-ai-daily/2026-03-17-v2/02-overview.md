# 先说结论：今天真正的变化是什么？

过去大家讨论 AI coding，很多时候还停留在：
- 这个模型能不能写代码
- 这个 agent 会不会改 bug
- 这个 prompt 好不好用

但这两天冒出来的信号说明，大家开始补的是更底层的问题：

## 1. 怎么把一个大任务拆给多个 agent 并行做
不是一个 agent 从头干到尾，而是开始有主 agent + subagents 的结构。

## 2. 怎么让 agent 不是“临时聊天工具”
而是能持续运行、随时唤起、甚至像工作进程一样常驻。

## 3. 怎么让 agent 真的能被托付
不是只会 demo，而是要有安全边界、部署方式、工程可靠性。

如果只记一句话：
**coding agent 正在从“能玩”进入“能进流程”的阶段。**
