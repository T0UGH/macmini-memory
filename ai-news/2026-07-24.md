## 💬 社区声音

1. **@xiaohongshu AI 博主整理｜AI 工程师必读的 6 种 Agent 模式（Anthropic 官方分类）**
   Anthropic 官方总结的 6 种 Agent 架构：① Prompt Chaining（固定步骤流水线）、② Routing（输入分类路由）、③ Parallelization（并行执行/投票）、④ Orchestrator-Workers（运行时动态分解）、⑤ Evaluator-Optimizer（写-评迭代）、⑥ Autonomous Agent（无固定路径自主规划）。社区共识：大多数所谓"生产级 Agent"其实是模式 1、2、5 加错误处理，真正的自主 Agent 仍是少数派。

2. **@xander｜Karpathy：AI 领域最大错误是还没掌握模型就开始折腾 Agent**
   Karpathy 指出，当前 AI 行业最常见的错误是团队在真正理解底层模型之前就强推 Agent 工作流。他以 2016 年 OpenAI 的失败经历为例，说明跳过模型理解阶段直接上 Agent 会导致数年时间浪费。这一观点引发大量工程师共鸣，被反复引用。

3. **@xiaohongshu 独立开发者｜AIHOT 月活突破 60 万，全流程超 10 个大模型节点**
   独立开发者分享 AIHOT（AI 资讯聚合站）后台架构：数百个信源 5 分钟级抓取 → 数据清洗 → 结构化 → 预筛 → 精选 → 聚类 → 展示，全流程超过 10 个大模型节点，自研聚类算法经过多轮回测和人工标注。案例说明：看似简单的聚合产品背后工程复杂度惊人，大模型已深入每个细节流程。

4. **@Andrew Ng｜1 小时课程：零基础构建 Agentic Knowledge Graph（含 Google ADK）**
   Andrew Ng 发布免费课程，系统讲解 Agentic Knowledge Graph 构建方法，包含 Google ADK 多 Agent 系统架构。社区评价：这一课程比 10 篇 Loop Engineering 文章更有价值，"Graph Engineer" 有望成为 AI 时代新职业方向。

5. **@orangesec｜AI Agent 工程骨架拆解：为什么 Prompt 只决定"做什么"，Harness 才决定"出错后还能不能做"**
   从一条 TypeScript 构建 Coding Agent 的运行轨迹出发，深入解析工具调用配对、流式中断恢复、会话树保存、上下文压缩等工程细节。核心观点：Agent 的工程含量往往藏在处理不确定性的那一层，Harness（测试框架）的重要性不亚于 Prompt 本身。
