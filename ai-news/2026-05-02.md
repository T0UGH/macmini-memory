# 2026-05-02 AI 动态简报

## 🔥 今日热点

1. **Google 发布 Gemini Enterprise Agent Platform，剑指 OpenAI / Anthropic**
   Google 在 Cloud Next 大会上推出 Gemini Enterprise Agent Platform，定位为企业级 Agent 构建、治理与编排的统一底座。内置 Agent Gateway（代理流量管控）、Agent Registry（资产索引）、Agent Identity（密码学身份）、Model Armor 安全防护，并支持超过 200 种模型（包括 Claude Opus 4.7）。同时推出 Inbox（Agent 统一监控台）和 Agent Designer（无代码流程编排）。企业版定价 $21–$30 / 用户 / 月。
   来源：https://cloud.google.com/blog/products/ai-machine-learning/introducing-gemini-enterprise-agent-platform

2. **Writer 发布事件驱动型 AI Agent，无需人工触发即可执行工作流**
   企业 AI 平台 Writer 推出事件触发型 Agent，可自动监听 Gmail、Gong、Google Calendar、Drive、SharePoint、Slack 等业务信号并执行多步骤工作流。新版本还加入 Bring-Your-Own-Encryption-Key、Datadog 可观测性插件、AI Studio 审计追踪等治理功能，对标 AWS、Salesforce、Microsoft Agentic Platform。
   来源：https://venturebeat.com/technology/writer-launches-ai-agents-that-can-act-without-prompts-taking-on-amazon-microsoft-and-salesforce

3. **NVIDIA 发布 Nemotron 3 Nano Omni：视觉 + 音频 + 语言三合一，效率提升 9 倍**
   NVIDIA 推出开源多模态模型 Nemotron 3 Nano Omni，将视觉、音频、语言统一在单一 30B-A3B MoE 架构中，支持高达 1920×1080 原生分辨率的 GUI Agent 操作，在 OSWorld 等基准上实现突破。已在 H Company 等计算机操作 Agent 中落地，适用于文档智能、客服监控等场景。
   来源：https://blogs.nvidia.com/blog/nemotron-3-nano-omni-multimodal-ai-agents/

4. **GPT-5.5 vs Claude Opus 4.7 vs Gemini 3.1 Pro：三足鼎立，格局生变**
   多方评测综合显示：GPT-5.5（OpenAI 首次全量重训练）在 Intelligence Index 排名第一（60 分），Claude Opus 4.7（4 月 16 日发布）在 SWE-bench Verified（87.6%）和 MCP Atlas（79.1%）上领先，Gemini 3.1 Pro（$2/$12 / token）在 GPQA Diamond 科学推理（94.3%）和性价比上优势突出。2026 年 4 月成为史上最大模型发布月。
   来源：https://www.buildfastwithai.com/blogs/best-ai-models-april-2026-comparison

5. **Microsoft Agent 365 正式 GA，企业 Agent 管理进入生产阶段**
   Microsoft 宣布 Agent 365 正式全面上市，将身份、安全、治理和管理能力延伸至企业内部所有 AI Agent 及跨 Agent 交互，标志着企业级 Agent 管理从实验进入大规模生产部署阶段。
   来源：https://x.com/i/web/status/2050251014691840015
