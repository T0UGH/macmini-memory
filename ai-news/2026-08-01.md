## ⭐ GitHub 新项目

### [awesome-llm-apps](https://github.com/Shubhamsaboo/awesome-llm-apps)
100+ AI Agent、RAG 应用与 Agent Skills 精选列表，全部免费开源，是目前最全的 LLM 应用实践合集。

### [browser-use](https://github.com/browser-use/browser-use)
让 AI Agent 能够操控浏览器访问网站、自动执行在线任务的框架，降低了 Agent 控制网页界面的工程门槛。

### [gemini-cli](https://github.com/google-gemini/gemini-cli)
Google 官方推出的开源 CLI 工具，将 Gemini 的能力直接带入终端，支持本地 AI Agent 交互。

### [ponytail](https://github.com/DietrichGebert/ponytail)
通过系统设计让 AI Agent 像"最懒的高级工程师"一样思考——最少的代码实现最优雅的解决方案，减少 Agent 过度工程的倾向。

### [autoresearch](https://github.com/karpathy/autoresearch)
Andrej Karpathy 出品，单 GPU 上自动运行 AI 研究代理的项目，探索模型自主训练与研究自动化的前沿方向。
