## 💬 社区声音

- **@dotey & 社区**：2026 年是 Agent 继续爆发的一年，AI 应用在特殊/边界场景可能反哺模型，类似 Manus 与 DeepMind 的深度合作模式。AI 应用不会被模型公司完全吃掉。

- **Harness Engineering 概念兴起**：模型是 CPU，Harness 是操作系统。2026 年真正的护城河不在模型本身，而在驾驭模型的系统工程能力。经历了三个阶段——Prompt Engineering → Context Engineering → Harness Engineering。

- **Figma 开放 MCP 应对 Google Stitch 2.0**：Figma 选择不自建大模型、专注做画布，让所有 AI Agent 都能接入，数据留在 Figma。这条开放路径未必是坏棋。

- **AEO（Agent Engine Optimization）成为新必修课**：越来越多人直接问 AI 而非 Google，SEO 之外还需要考虑如何让 AI Agent 更容易推荐你的产品——结构化内容、Schema markup、真实社区讨论布局是关键。

- **2026 年值得研究的 AI Agent**：Claude Code、OpenClaw、Qoder 被社区高频提及，其中 Claude Code 和 OpenClaw 被认为是年度最值得投入学习的两个 Agent。
